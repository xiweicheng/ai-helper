# 多标签页自动化：让 AI 帮你做竞品调研

做竞品调研的人大概都有这个体验：打开 5 个竞品网站，逐个浏览功能页面，把定价、功能列表、差异化卖点复制到文档里，最后整理成对比表格。

这个过程没什么技术含量，但特别耗时。5 个网站搞下来，半小时就过去了。

今天介绍的开源 Chrome 扩展 AI Helper，能把这件事缩短到 1 分钟左右。它的标签页管理 + 内容提取 + 并行执行能力，正好是竞品调研的利器。

## 需要用到的工具

AI Helper 内置的 44 个工具中，做竞品调研主要用到这几个：

| 工具 | 作用 |
|------|------|
| `manage_tab` | 打开、关闭、切换标签页 |
| `page_content` | 提取页面文本内容 |
| `extract_data` | 提取结构化数据（表格、链接等） |
| `ai_search` | 联网搜索补充信息 |

加上 ReAct 推理循环的编排能力，这些工具会被自动组合起来完成完整任务。

## 完整操作流程

打开 AI Helper 侧边栏，直接描述你的需求：

```
帮我打开这三个网站，提取它们的定价信息，整理成一个对比表格：

1. https://product-a.com/pricing
2. https://product-b.com/pricing  
3. https://product-c.com/pricing
```

接下来 AI Helper 会自动执行以下步骤。

### 第一步：打开标签页

AI 调用 `manage_tab` 工具，依次打开三个 URL。每个标签页加载完成后继续下一步。

### 第二步：提取内容

对每个标签页调用 `page_content`，提取页面的文本内容。如果定价信息在表格里，会调用 `extract_data` 提取结构化表格数据。

### 第三步：并行执行

这里有个技术细节值得说一下。三个网站的提取操作是互相独立的，AI Helper 会用 `Promise.all` 并发执行：

```javascript
// 简化示意：并行提取三个页面的内容
const results = await Promise.all([
  extractPageContent(tab1),
  extractPageContent(tab2),
  extractPageContent(tab3)
]);
```

并行执行的好处是，三个页面的提取同时进行，总耗时约等于最慢的那个页面，而不是三个加起来。

### 第四步：对比分析

三个页面的内容都提取完后，AI 会对比分析各家的定价方案，提取关键信息：

- 价格区间
- 免费额度
- 付费档位
- 核心差异点

### 第五步：输出对比矩阵

最终输出一个 Markdown 格式的对比表：

```markdown
| 产品 | 免费版 | 入门版 | 专业版 | 企业版 |
|------|--------|--------|--------|--------|
| Product A | 5次/天 | ¥29/月 | ¥99/月 | 联系销售 |
| Product B | 10次/天 | ¥39/月 | ¥129/月 | ¥299/月 |
| Product C | 无 | ¥49/月 | ¥149/月 | ¥399/月 |
```

## 可视化输出

除了 Markdown 表格，AI Helper 还支持 Mermaid 图表。比如你可以要求生成一个功能对比矩阵图：

```
用 Mermaid 画一个三个产品的功能对比图
```

AI 会生成 Mermaid 语法的图表代码，在支持 Mermaid 渲染的编辑器里直接显示为可视化图表。

结果也可以导出成 Word 或 PDF 文件，直接发给团队。

## 实际效果对比

我实际测了一下，让 AI Helper 做一个 3 个竞品的定价对比：

| 环节 | 手动操作 | AI Helper |
|------|----------|-----------|
| 打开网站 | 1分钟 | 5秒 |
| 浏览提取信息 | 15分钟 | 10秒 |
| 整理对比表 | 10分钟 | 5秒 |
| 格式化输出 | 5分钟 | 自动 |
| **总计** | **约30分钟** | **约1分钟** |

当然，AI 提取的信息可能需要你人工复核一遍，但整理框架的工作量已经省了 90%。

## 不只是竞品调研

同样的能力可以用在很多场景：

- **技术选型**：打开几个框架的文档，提取核心特性做对比
- **购物比价**：打开多个电商页面，提取价格和规格
- **文献整理**：打开多篇论文页面，提取摘要和关键词

只要你的需求是"打开 N 个页面 → 提取信息 → 整理对比"，AI Helper 都能帮你搞定。

## 小结

竞品调研这类任务，核心痛点不是分析有多难，而是机械重复操作太耗时。AI Helper 的价值在于把这些机械操作自动化了，你只需要描述需求，剩下的交给 ReAct 循环来编排工具。
