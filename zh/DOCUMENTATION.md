### 核心数据流

```
用户输入 → Side Panel (选择 Agent, 可选图片/文件附件, 可选 Skill/MCP, 可选 @网页上下文)
  → chrome.runtime.sendMessage('CALL_API')
    → Background: MCP 工具注入 → 工具预筛选 → ReAct 推理循环
      → Token 预算管理 → 上下文压力监测 → Token 统计记录
      → LLM API 调用 (OpenAI 兼容, 带重试和指数退避, 流式响应 + DeepSeek thinking)
        → 如需工具: 工具确认检查（敏感操作）→ 执行工具
          ├── Background 直接执行（标签页管理、书签搜索等）
          ├── 委派 Content Script（页面交互、内容提取等）
          ├── 委派本地 Agent（文件读写、命令执行、MCP 工具等）
          └── Offscreen 文档（剪贴板读写）
        → 工具观察提示（零成本内联规则）→ 结果缓存 → 反馈给 LLM
      → 子任务拆解与并行执行（plan_task 集成，支持 Agent 子任务分派）
      → Checkpoint 断点保存 → 后置反思：多维度质量评估 → 合格/修订/重试
    → chrome.runtime.sendMessage('API_COMPLETE')
  → Side Panel: Markdown 渲染, Mermaid 图表渲染, 质量评估展示, Token 统计更新
```

## 核心功能

### 1. 多模态输入

#### 图片识别输入
支持在对话中附加图片，通过 Vision API（OpenAI 兼容）进行多模态理解和问答：

- **图片压缩**：自动压缩大图（1024px + JPEG 65%），减少 Token 消耗
- **独立 API 配置**：支持为图片识别配置独立的 API Base / API Key / 模型
- **全局开关**：可随时开启/关闭图片输入功能
- **多图上传**：同时附加多张图片进行对比分析

#### 文件上传问答
在浏览器端直接上传文件并提取内容，无需依赖 Agent 服务也可使用：

- **支持格式**：
  | 格式 | 提取引擎 | 说明 |
  |------|----------|------|
  | PDF | PDF.js (pdfjs-dist) | 完整文本提取，支持多页 |
  | Word (.docx) | mammoth.js | 富文本转纯文本 |
  | Excel (.xlsx/.xls) | SheetJS (xlsx) | 多 Sheet CSV 导出 |
  | 纯文本 | FileReader API | 50+ 扩展名自动识别 |
- **Agent 优先上传**：连接 Agent 后自动上传至工作目录，支持大模型直接操作原始文件
- **浏览器降级**：Agent 不可用时自动切换为浏览器端提取
- **文件预览栏**：显示文件名、大小、提取状态、支持删除

#### 图片标注编辑器

- **键盘快捷键**：Enter 确认、Esc 取消
- **编辑后自动更新**：标注结果立即更新到附件列表

### 2. 多助手管理（Agent 系统）

支持创建和管理多个自定义 AI 助手，每个助手拥有独立的系统提示词和工具权限：

- **内置模板**：默认助手、代码审查专家、网页自动化助手、数据分析师、文档撰写助手
- **自定义 Agent**：创建专属助手，设置图标、名称、系统提示词、模型、温度和工具权限
- **Agent 选择器**：侧边栏顶部快速切换，支持 `@Agent名称` 快速切换

- **子任务分派**：`dispatch_task` 支持并行分派，子 Agent 独立执行并返回结果
- **Agent 持久化**：基于 `chrome.storage.local`，跨重启保持

### 3. ReAct 推理循环

项目采用 ReAct（Reasoning + Acting）模式作为核心推理引擎：

1. **MCP 工具动态注入**：每次推理前自动从 Agent 拉取最新的 MCP 工具列表，注入到 RAW_TOOLS 中
2. **工具预筛选**：正式调用主力模型前，用一次轻量 API 调用判断需要哪些工具，将 40+ 个内建工具缩减为 5-10 个相关工具，大幅减少 Token 消耗。简单问题可直接回答跳过推理循环
3. **推理循环**：LLM 思考 → 决定调用工具 → 执行工具 → 结果反馈 → 继续推理
4. **Token 预算管理**：按模型上下文窗口动态计算可用 Token 预算（80%），按 Token 数截断，保留 tool_calls/tool 消息配对完整性
5. **上下文压力监测**：三级监测（safe / warning / critical），自动触发摘要压缩
6. **上下文智能压缩**：对长引用内容自动生成摘要压缩，避免永久占据上下文空间
7. **工具结果缓存**：并行工具结果自动缓存（上限 30 条）
8. **并行工具执行**：同一轮中标记为可并行的工具通过 `Promise.all` 并发执行
9. **任务拆解**：`plan_task` 支持顺序、并行、条件三种执行策略，子任务失败支持重试/回滚/继续
10. **子任务分发**：`dispatch_task` 支持将子任务委派给其他 Agent 并行执行
11. **流式响应**：支持 OpenAI 流式响应（SSE）与 DeepSeek thinking，回复实时逐字显示；Agent 命令输出也实时流式呈现
12. **澄清机制**：信息不完整时弹出澄清对话框，循环计时自动暂停，支持推荐选项
13. **多级超时控制**：API 超时 5min、工具超时 10min、整体循环超时 30min
14. **取消控制**：用户可随时取消推理循环，按会话隔离
15. **SW 重启恢复**：Keepalive 端口监测 SW 静默重启，自动通知 Side Panel 恢复。后台任务状态持久化到 `chrome.storage.session`
16. **Checkpoint 断点**：每轮推理后自动保存 Checkpoint，支持任务中断后恢复继续执行

### 4. 反思系统（多级质量保障）

| 级别 | 说明 | 触发条件 |
|------|------|----------|
| **子任务反思** | 评估子任务结果完整性和相关性 | 仅标记为 complex 的子任务（可配置） |
| **后置反思** | 最终答案 7 维度质量评分 | 每轮推理完成后自动执行 |

后置反思评分维度：完整性、准确性、相关性、工具使用、清晰度、安全性、效率。根据评分阈值自动决定：通过 (≥7)、修订 (5-7)、或重新执行 (<5)。

> 工具执行结果的质量提示不再单独发起 LLM 反思调用，改由零成本内联规则「工具观察提示」（`[Observation Hint]`）承担：在工具失败 / 返回空结果 / 结果超大被压缩时，向结果追加一句规则化提示，引导模型自我调整策略。

### 5. 上下文压缩与 Token 预算管理

智能上下文管理策略：

- **上下文占用指示器**：输入框下方实时显示占用百分比（环形进度 + 安全/警告/危险三档配色），点击可查看系统提示词、工具定义、历史消息、当前输入四项明细
- **手动压缩上下文**：一键将历史消息压缩为 AI 结构化摘要（会话级持久化，发送新消息前可撤销；再次压缩时旧摘要与新消息合并）
- **自适应 Token 估算**：中文字符 ~1.5 chars/token，英文 ~4 chars/token
- **上下文窗口自动检测**：根据模型名自动推断上下文窗口（支持按模型自定义映射，默认 256K）
- **消息预算 = 上下文窗口 - 系统提示词 - 工具定义 - 输出预留**
- **上下文压力三级监测**：safe / warning / critical
- **消息摘要**：压力达到 critical 时自动对早期消息生成摘要，替代原始内容
- **引用压缩**：长引用/选中内容自动压缩为摘要，避免永久占据上下文
- **Token 级别截断**：70% 开头 + 30% 结尾 + 截断标记

### 19. 长期记忆系统

AI Helper 具备长期记忆能力，可以跨会话存储和检索用户信息。记忆的提取、存储与召回由 **Agent 服务**执行（条目落在 `~/.ai-helper-agent/memory/global-memory.json`，派生向量缓存 `memory-vectors.json`），扩展端只负责转发与本轮注入装配：

- **记忆存储**：AI 自动识别对话中的重要信息（偏好、知识、决策），主动调用 `agent_memory` 存储
- **记忆类型**：支持事实记忆（fact）和对话摘要（summary）两种类型
- **双通道召回**：默认走关键词通道；在选项页「记忆」Tab 配置 embedding 后叠加语义向量通道，两路按名次融合（语义档取向量相似度 top-K，不设绝对分数门槛）
- **三档降级**：`none`（未启用向量，纯关键词）/ `remote`（OpenAI 兼容端点）/ `local`（本地模型，需 RAG 依赖）；向量不可用时静默回落关键词通道，不影响对话
- **向量指纹与重建**：向量按「来源 + 模型 + 维度 + 前缀」指纹归档；换配置后旧向量不可比，需在「记忆」Tab 点「重建向量索引」，状态卡以「已陈旧」提示
- **记忆管理**：自动审查记忆质量（review），合并重复记忆，淘汰低价值记忆（compact）
- **标签分类**：偏好、知识、决策、自定义四类标签体系
- **重要性评分**：1-10 分，帮助记忆系统做优先级排序
- **自动归档**：facts 上限 50 条，summaries 上限 20 条，超出自动触发压缩清理
- **携带量控制**：侧边栏「记忆」开关与历史条数限制（不限制 / 最近 2~200 条）为全局设置，决定每轮带入的记忆上下文

### 20. ReAct Checkpoint 断点续接

任务执行过程中自动保存检查点（Checkpoint），支持中断后一键恢复：

- **自动保存**：每轮 ReAct 推理完成后自动保存 Checkpoint 到 IndexedDB
- **SW 重启恢复**：Service Worker 静默重启后通过 `chrome.storage.session` 自动恢复状态
- **手动恢复**：中断任务的消息卡片显示「继续执行」按钮，点击可追加描述并恢复执行
- **流式输出保留**：恢复后的流式输出完整保存到消息历史，刷新页面不丢失
- **TTL 自动过期**：Checkpoint 保存 7 天后自动清理，避免数据堆积
- **多连接管理**：IndexedDB 支持 SW + Side Panel 双连接安全关闭与重建

### 21. @ 网页 Tab 选择器

### 22. Shadow DOM 深度穿透

### 28. Agent 重启与自动更新

代理服务支持在线重启和一键更新，无需手动操作终端：

- **在线重启**：`/api/agent/restart` 两阶段重启（spawn helper → 等待旧进程退出 → 启动新进程）
- **自动更新**：`/api/agent/update` 执行 `npm install -g ai-helper-agent@latest` 并自动重启（90s 超时保护）
- **更新冷却**：10 秒内不允许重复重启/更新，防止意外并发

### 29. 上下文增量摘要

### 30. 定时任务

支持创建定时任务，在指定时间自动执行预置指令，并将结果写入绑定的宿主会话：

- **三种调度规则**：一次性（多少分钟后 / 指定时间点）、间隔（如 `30m` / `2h` / `1d`）、Cron 表达式（5 段式）
- **网页上下文**：可绑定指定网页作为上下文，支持「抓取正文」或「仅使用 URL」两种模式
- **宿主会话**：任务执行结果落在一个宿主会话中；宿主会话被删除后，任务执行时自愈新建专属会话
- **调度引擎**：基于 Chrome Alarms 调度，Service Worker 重启后自动重建闹钟
- **管理与控制**：管理面板支持创建 / 编辑 / 删除 / 启用 / 停用 / 立即执行
- **运行历史**：记录每次执行的状态、耗时与错误（最多 50 条），面板内可展开查看
- **桌面通知**：任务完成 / 失败时按「定时任务通知」开关弹出桌面提醒（默认开启，无声音等其他提醒渠道时尤为重要）；点击通知打开侧边栏
- **结束条件**：间隔任务支持「最多执行次数」与「截止时间」自动停用
- **手动立即执行**：触发后自动切换到宿主会话并滚动到底部等待结果

### 31. 桌面通知与完成反馈

任务在后台执行时也能及时获知结果（选项页「基础」→「完成反馈」区域统一管理）：

- **三个独立开关**：任务完成 / 失败通知、定时任务通知、交互提醒（AI 需要确认或澄清时）——均可在选项页随时开关、实时生效
- **任务完成 / 失败通知**：仅在看不到侧边栏时弹出（可见时不打扰）；成功通知自动消失，失败通知停留至手动关闭；点击通知打开侧边栏并定位到对应会话
- **定时任务通知**：定时任务在后台执行，无声音等其他提醒渠道，开关开启时总是弹出（默认开启）
- **交互提醒**：推理循环因敏感操作确认 / 需求澄清而等待用户时弹出桌面提醒，避免任务卡在弹窗而用户不知情；仅在看得到侧边栏时不打扰
- **多实例防重**：标签页绑定模式可同时打开多个侧边栏实例，通知创建权统一收敛在 Background（全局唯一），并按「发起任务的实例」精确判定可见性，绝不重复弹窗
- **完成反馈音效与彩带**：成功 / 失败不同音效、成功彩带动画，均独立开关控制

### 32. 主题切换（亮 / 暗 / 跟随系统）

整套界面基于语义化颜色 token 构建，支持三态主题（默认亮色），切换即时生效并在所有界面间同步（存储键 `appTheme`）：

- **三态**：跟随系统（随操作系统 `prefers-color-scheme` 实时翻转）/ 亮色 / 暗色
- **两个入口**：选项页「基础」→「外观」三分段控件直接选择；侧边栏顶部「更多」菜单中的「主题：当前态」项按 亮 → 暗 → 跟随系统 循环切换
- **跨页同步**：侧边栏、选项页、划词浮层任一处切换，其余页面无需刷新即刻跟随
- **无首帧白闪**：已解析主题镜像到本地，脚本启动前先落到根元素，暗色用户打开页面不会先闪一下亮底

- **导出恒定亮纸张**：PDF / Word / HTML 导出与富文本复制始终为白底黑字的亮色纸张，不随暗色主题变化，保证离线阅读与打印可读性
- **暗色质量把关**：暗色经逐浮层对比度扫描（WCAG AA）与大面积白斑检测验收，杜绝「调得不协调」的漏网配色

### 33. 子任务完成度客观取证校验

与「反思系统」的主观自评互补：反思是模型对答案质量的主观评分，本特性则是用真实页面 / 命令证据**客观**核验 `plan_task` 拆出的子任务是否真正达成，而非依赖模型自述（默认关闭时现有行为逐字节不变）。

- **判据声明**：子任务可附 `doneCriteria` 验收标准，支持 `element_exists` / `element_absent` / `text_contains`（必设 `expected`）/ `attribute_equals` / `url_matches` 五种检查类型。
- **客观取证**：内容端用 `deepQuerySelector` / `deepGetText` 穿透多层 Shadow DOM 与同源 iframe 定位目标，`selectorQueryable` 探语法合法性；三态结论 `satisfied` / `unmet` / `indeterminate`，取证通道不可用时不谎报为未达标。
- **自动重跑回路（可选）**：四闸门（可重试 / 有进展 / 有预算 / 未超次）驱动未达标子任务回炉；`isStrictSubset` 严格真子集判定保证缺项集单调收缩，不收缩即停止重跑防振荡。命令取证支持“只读硬拦”与“agent 三档门控（allow/confirm/deny）”两种模式。
- **即时不阻断**：在每个子任务 `onDone` 内现场即时取证（尽力而为），单条取证带超时；取证结果以 `completionNote` 上报，不影响主循环。
- **开关**：位于选项页「推理」Tab 内的「完成度校验」开关与「完成度自动重跑」子开关（后者仅在前者开启时展开），均随配置导入 / 导出持久化。

### 34. 文件产物声明识别与可点击路径

连接代理服务后，AI 通过脚本动态生成的文件也能被正确归入「文件产物」面板，回答里的文件路径可直接点击定位：

- **产物声明识别**：系统提示词引导 AI 用文本约定 `[[artifact:路径|说明]]` 声明脚本产物。静态分析（从执行日志的 `agent_file` 提取）作为地板，声明补缺口，按路径去重合并；每项标 `source: 'static'|'declared'`。

- **显示期剥离标记**：`[[artifact:...]]` 仅用于产物解析，渲染前从展示文本中剥离，用户不会看到标记原文；不含标记的消息原样保留（保护代码块空行保真）。
- **聊天内可点击路径**：回答文本中的文件路径自动识别转为可点击链接。产物可信路径直接转；其余候选采用 fail-closed——仅当解析到工作目录根内且文件确实存在才转链，避免误链系统路径。本地绝对路径不跨空格切词。
- **点击定位**：点击路径链接复用工作目录面板的 `locateFileInWorkspace`，在侧边栏自带的「工作目录」面板中定位并高亮该文件（而非系统 Finder）。

### 35. 本地语音输入（本地 STT）

用说的代替打字，且**音频不出本机**。识别在本地代理服务内跑 ONNX 模型，不需要云端 ASR，也不需要额外的 API Key：

- **三段式门控**：依赖（`sherpa-onnx-node`）× 模型（`online` 流式 / `offline` 定稿）× 总开关，三者同时就绪 🎤 才出现在输入框右侧；缺任一环按钮直接隐藏，不做「点了才报错」。
- **两种节奏**：边说边出流式草稿（服务端节流 150ms，句尾用 VAD 提交为稳定片段）；松手后 offline 模型整段重转，补标点、规整数字。
- **接管不丢字**：`Alt+V` 在焦点位于网页时也能收尾，`Esc` 取消。麦克风授权只能在标签页内完成（侧边栏形态下 Chromium 不弹授权框），选项页「语音」Tab 提供「去授权」入口。
- **单键触发（可配置）**：选项页「语音 → 快捷触发」可分别勾选**右侧 Alt** / **右侧 Ctrl**，默认全关；两个都勾 = 任一都能触发，`Alt+V` 始终可用、不受影响。语义是「按下再松开」算一次，按住期间敲了别的键就整次作废（AltGr 布局不误触），侧边栏与网页里同时生效、勾完立即生效。
- **麦克风可选**：选项页「语音 → 输入设备」列出本机所有录音设备（滤掉 Chrome 的 `default` / `communications` 伪设备），默认「跟随系统默认」；选了具体设备就按 `deviceId: { exact }` 采集，新插的 USB / 蓝牙麦克风点「刷新列表」或直接插拔（监听 `devicechange`）就会出现。选中的设备被拔掉时自动回退系统默认，并在录音条上明说一句，不静默换设备。读不到设备列表时不会一直显示「正在读取」：枚举带 2.5s 超时，并分别告知是超时、环境不支持还是未授权（后者可直接点「授权麦克风」），已授权但枚举卡住时会先唤醒音频服务再重试一次。
- **定稿不自动发**：识别结果只写进输入框草稿，是否发送由用户决定。
- **可靠的录音条**：24 根音量柱 + 计时 + 状态文本；隐藏前先把焦点交还输入框，`aria-live` 只挂在状态文本上，避免读屏被计时器刷屏。
- **资源可控**：单次录音 5 分钟上限、会话空闲 30 秒回收、并发 1、RSS 超 3.5GB 自动退化为流式文本、引擎空闲 10 分钟卸载；offline 推理跑在独立 worker 线程，不阻塞代理主线程的事件循环。
- **入口**：选项页「语音」Tab（检测 / 一键安装依赖、扫描与导入模型包、切换语言与开关）。完整启用步骤与模型包结构 → [`docs/Voice-Input-Local-STT.md`](../Voice-Input-Local-STT.md)

### 36. 侧边栏待办清单

- **轨道第 6 入口**：与「工作目录 / 收藏 / 消息目录 / 搜索」并列，图标右下角徽标实时显示未完成条数，收起面板也能看到还有几件事。
- **右缘浮层**：320px 宽覆盖在聊天区之上，窄侧边栏下最宽 `100vw - 60px`，不会把左侧「执行中会话停靠条」压在自己底下。轨道内叠放次序明确，与「定时任务」同开时待办清单仍可见可点。
- **底边贴住输入框上沿**：面板底部锁定在问答输入区上沿上方 8px（不是居中浮层）。可用高度按「输入区上沿 − 顶部保留」算足后写进 `--todo-max-h`；以前是拿面板自己的底边当基准，等于自己限制自己，实测白白少掉 100px+（约 2 条，条目一多就只能露三四行）。位移 `--fit-y` 允许正值（悬空就向下补齐）也允许负值（越界就向上让开），位置一次定好后不做过渡，不会每次打开都往下滑一段。输入区敲长文变高时 `ResizeObserver` 让面板往上让位，量不到输入区时回退按轨道下沿兜底，矮窗口下仍保留最小可用高度。
- **切 Tab 不跳高**：面板高度只增不减——添加条目时继续按内容长高，长到可用上限就不再长（改由列表区滚动）；切到条目更少的已完成 Tab、或删掉条目时保持已有高度不回缩，不会整块上下跳。锁定只在一次打开内生效，重新打开面板才按新内容重算。
- **回车即加**：顶部输入框敲回车（或点 `+`）立刻新增一条，焦点自动留在输入框，可连续记录；在「已完成」Tab 里添加会自动切回「待办」Tab，不会出现「加了但看不见」。
- **双 Tab 而不是折叠分组**：「待办」与「已完成」一次只渲染一组，各自带条数。之前的折叠分组会把已完成顶到可视区之外，用户根本找不到已完成的条目。头部进度写成「完成 1 / 3」，处理中不为 0 时再补一句「· 处理中 1」（为 0 不占字），不再只给一个看不出分子含义的 `0 / 3`。
- **三段状态**：点行首状态圈按 待处理 → 处理中 → 已完成 循环，同时行尾「⋯」菜单里给出文字版动作（开始处理 / 标记完成 / 退回待办），标记完成不能只藏在一个圈的点击上。处理中行用圈内实心点 + 淡底表示，不跟左侧色条抢同一个位置。
- **完成可撤销、可智能恢复**：标记完成后该条位置浮现内联撤销条（6 秒），标题过长由文本侧省略号承接、按钮不参与收缩（否则中文两字会被压成竖排两行）；点一下回到原位置而不是列表末尾。已完成 Tab 里每行有「恢复」入口，文案写明恢复到哪——完成前是「处理中」就回到处理中，否则回到待处理。
- **优先级色条**：菜单里四个色块直接选（高 / 中 / 低 / 无，当前档位高亮），条目左侧 3px 竖条即优先级：高=`--danger-500`、中=`--warning-500`、低=`--brand-500`，未设置则不出条。竖条只代表优先级这一件事。
- **外部链接**：菜单里「添加 / 编辑链接」开行内输入框，回车即关联。只接受 http/https，不带协议自动补 `https://`；非法链接在校验层就被拒，不会先上屏再回滚，也会弹「仅支持 http/https」。关联后行内显示域名胶囊（普通按钮，`href` 不写进 DOM），点击才开新标签；清空回车即移除链接；「取消」按钮在 `pointerdown` 就结束编辑态，不会被自动保存抢跑。
- **行内编辑**：标题、备注、截止日、链接都在原行内改，不弹新窗口。备注用 `Ctrl`/`⌘` + `Enter` 保存、`Esc` 取消；截止日为日期粒度，逾期条目以警示色加 ⏰ 标记。
- **改到一半不丢字**：正在输入的标题/备注/截止日/链接都是「草稿」，其它条目被增删改触发整块重渲染时，草稿内容、焦点与光标位置都会还原到原处，保存或取消才清空；一次关联只弹一条提示（重渲染拆掉脏输入框时浏览器会补发 `change`，不能存两遍）。
- **拖拽排序**：只在「待办」Tab 内生效，插入位置用虚线段提示；跨组移动一律走状态圈或菜单，避免拖一下就把状态改了。
- **悬停才浮现的动作**：行内常驻只有状态圈与标题；填入输入框 / 编辑 / 更多在悬停或键盘聚焦时才出现；备注、截止、链接、优先级、删除统一收进行尾「⋯」，`清除已完成` 收在已完成 Tab 顶部。菜单挂在 `fixed` 层、宽度自适应文案且禁止换行（不会再出现一个词拆两行），按视口右缘与高度夹取，超长时可滚动。菜单顶上不画分割线——分割线的语义是「上面还有内容」，首项带着它在空菜单顶上就是一条没来由的横线。
- **头部「⋯」= 统计 + 一个导出入口 + 一个导入入口**：入口只有三项——「待办统计 / 导出… / 导入…」，每项都带图标（混排会让文案左缘参差）。**导出**点开一张选项弹窗，范围（全部 / 待办 / 已完成，各自带条数）与格式（JSON 可回导 / Markdown 可读）在同屏一次选完，确认再落文件，文件名 `ai-helper-todos[-active|-done]-YYYY-MM-DD.ext`；选到空范围时确认按钮直接禁用并写明「这个范围里没有待办」，绝不生成空文件——空文件导回去等于用空数据覆盖。以前拆成「导出全部 / 导出待办 / 导出已完成」再套一层格式选择，六项菜单点两次才出文件，现在入口加确认两次点击就够。
- **导入：先选文件，再选怎么导**：菜单里只有一个「导入…」；选文件（只放行 `.json`，`cancel` 事件也接上，取消不会让流程悬着）并解析成功后，弹窗里给出「文件 N 条 / 当前清单 M 条」和两种方式——**合并**与**替换全部**。合并只往后追加、同 `id` 跳过不覆盖，失败只摘掉本次新增的条目；替换选中即在弹窗里亮出「将删除当前全部待办，写入文件里的 N 条，不可撤销」，不再叠一个全局确认框，落库时先删后写，**写失败会把原数据写回库**，避免一次失败把整个清单清空。空文件 / 坏 JSON 都拒绝并保留现有数据，提示区分「JSON 解析失败」与「结构不对」——坏文件连方式都不问，免得白选一遍。导入成功自动切回「待办」Tab，避免停在已完成后看不见新增条目。
- **快捷键（Alt + 字母，作用对象是当前行）**：`Alt+T` 开关面板、`Alt+A` 聚焦添加框、`↑`/`↓` 在条目间移动焦点、`Alt+B` 加备注、`Alt+L` 加链接、`Alt+D` 标记完成 / 退回待办、`Alt+P` 循环优先级。全部登记在 `Alt+/` 快捷键面板里，行菜单里这些动作的右侧也直接标出 `Alt+D` / `Alt+B` / `Alt+L` / `Alt+P` 角标（没有快捷键的项不占位），不用先背再试。整块重渲染后焦点会送回同一行，否则按一次方向键焦点就掉到 `body`。
- **统计视图（独立浮层，不挤列表高度）**：头部「待办统计」弹一张只读卡片——完成率（大号百分比 + 进度条 + 已完成 N / M）、四态数量（待处理 / 处理中 / 已完成 / 逾期，逾期为 0 不高亮）、近 7 天每个自然日完成数柱图（按当周最大值归一，悬停显示「完成 x · 新增 y」）、今日新增 / 今日完成 / 连续完成天数 / 未完成的高优先级条数。`Esc`、点遮罩、右上 `×` 三种关法，关掉即摘键盘监听；浮层层级 10015 低于列表菜单的 10020，菜单弹出时不会被它盖住；统计层开着时切换语言会立即重刷。
- **单条转成提问**：只把**这一条**的组合文本（标题行 + 状态/优先级/截止/备注/链接）追加到输入框现有草稿之后，回车即发给 AI 让它做任务规划或方案设计；行菜单里的「复制本条 / 复制并附提问模板」则把同一份文本直接写进剪贴板（后者再附一段提问模板），不想占用输入框时用这条。批量填入已移除：积压越多，把整份清单塞进输入框越没处下手。
- **拖拽条目到输入框**：把待办行拖到问答输入框，落下的也是同一份组合文本，可以接着追问。
- **语言热切换**：面板骨架（标题、Tab、占位符、按钮 tooltip）都挂 `data-i18n*` 由 `applyI18n` 统一填充，JS 拼出来的列表与统计浮层走 `subscribe` 重渲染，首屏再补一次时序兜底——切语言立即生效，不需要关面板，更不需要重开插件。
- **可靠落库**：数据存 IndexedDB `todos`（DB v7），另在 `chrome.storage.local.todoStatsLog` 记一份 90 天的完成流水（`{ 'YYYY-MM-DD': { added, done } }`，读-改-写串行、按天裁剪、失败吞掉不影响待办主流程）。采用乐观更新——界面先变，落库串行排队避免并发互踩；失败只撤销本次操作的那一条、不牵连期间已成功的写，并广播回滚让界面如实退回，同时弹出「保存失败」提示，绝不静默吞掉失败。写操作统一返回 `{ok, reason}`（无效状态 / 无效链接 / 落库失败 / 条目不存在），校验不过不进乐观更新。

### 37. 会话归档区与执行中会话停靠条

会话开太多会有两类干扰，各有解法：不会再问答但又不忍删的会话需要能「移出视野」；同时在跑好几个任务时，不该在很多标签里选来选去。

**归档区（可逆移出视野，不是删数据）**

- **只是离开视野**：归档写 `session.archivedAt`，消息、工作目录绑定、ReAct checkpoint 原样保留；`loadSessions()` 默认过滤归档会话，`{ includeArchived: true }` 才拿全量。
- **三处入口统一隐藏**：标签栏、「全部会话」下拉、全局消息搜索都看不到归档会话（搜索走 `db.searchActiveSessionsMessages` 与搜索面板的 `visibleSessions` 两道过滤），不会出现「搜得到但标签里找不到」。
- **入口不占常驻空间**：「全部会话」面板底部 `归档区 (N)` → 全屏归档面板（层级高于会话列表）。面板内按归档时间分组、可搜索、点行即恢复并进入，悬停行尾出「恢复 / 彻底删除」。
- **三个归档入口**（列表行按钮、标签右键菜单、归档面板）走同一个 `archiveSessionFlow`；**执行中或有排队任务时拒绝归档**并说明原因（`isSessionArchivable`），避免把正在写结果的会话藏起来。
- **归档掉当前会话会自动切走**：切到最近更新的会话（一个不剩则新建），否则用户会停在一个标签栏里看不见的会话上；`switchToSession` 另有一道兜底——切到归档会话先自动解档（收藏、旧入口、定时任务都可能直达）。
- **彻底删除**复用普通删除的清理路径（队列条目 / 附件 / 完成标记 / checkpoint），二次确认文案明说「消息与执行记录都无法恢复」。
- **定时任务自愈**：宿主会话被归档时 `scheduler.resolveHostSession` 视为不可用并重建专属会话，否则执行结果会写进用户看不见的会话。

**执行中会话停靠条（`src/side_panel/session-dock.js`）**

- **不新建运行状态**，只消费既有信号：后台 `QUERY_SESSION_RUNNING` 回执（权威）+ `generatingSessionIds` / `pendingCallApiSessionIds` + `completedSessionIds` + 队列 store + `EXECUTION_STATUS_UPDATE` + `SCHEDULED_TASK_RUN_STATE`。不会出现「停靠条说在跑、后台早停了」的第二真值。
- **三态芯片**（26px 圆，当前会话永不出现）：执行中=品牌色 + 呼吸光环 + 外圈旋转弧，tooltip 显示「正在执行：Write · 子任务 2/3」；排队中=琥珀色 + 条数徽标；完成=绿色 ✓ + 一次性脉冲 + `HH:mm` 完成时刻。
- **悬停主行是用户的问题而不是会话标题**：优先取排队原文，其次取该会话最后一条用户消息（真值以 IndexedDB 为准，内存快照可能停在上一轮），都没有才回落标题；标题与问题不是同一件事时才在副行补上标题。
- **点芯片 = 打开会话并定位到那一轮用户问题**：`focusMessageInView` 以 `instant` + `block: 'start'` 贴顶滚动，复用既有的 `bookmark-highlight` 闪烁 2 秒（不新造第三种高亮）。落在「问题」而不是「回答」：回答在执行中不断变高，定位过去要么停在半截要么很快跑出视野。排队原文尚未入库、标题回落没有对应节点，这两种情况**不做假定位**，只走原有的恢复滚动。
- **完成态不自动消失**（自动消失等于把提示价值丢掉）：点进会话自动移除；悬停 `×` 只对完成态与陈旧态出现（执行态画 `×` 会被读成「取消任务」），`×` 结果持久化，该会话下次开跑自动解除。
- **条目放不下时 `+N` 聚合**：整条最多占 8 个位置，超过则画 7 条 + 第 8 位换成 `+N` 芯片；滚动放在正常宽度（220px）且可滚的溢出浮层里（26px 芯片列塞滚动条没法用），悬停/聚焦展开、点击钉住、`Esc` 收起。同组按时间降序，保证被折叠的一定是最老的。
- **执行状态卡死时陈旧降级**：`isEntryStale` 三条同时成立才判陈旧（只对 running 生效 + 后台权威集合已不认这个会话 + 超过 90s 没收到执行更新），降级后转灰 + 虚线描边 + 停动画 + tooltip 改「状态可能已失效」+ 露出 `×`（文案「移除失效条目」）。两个时间基准都为 0 时不判——宁可少报不可误报。
- **位置与让位**：贴左缘从聊天区顶部向下堆叠（左侧垂直中心已被消息跳转热区 `.chat-nav-hotzone` 占住），出现时给 `.chat-container` 留 34px 走廊让排版让位，而不是把芯片半透明叠在正文上。
- **性能与可访问性**：面板隐藏时暂停校准、切回立即补一次；`EXECUTION_STATUS_UPDATE` 一轮几十条，渲染 250ms 去抖。芯片是可 Tab、可 Enter 的 `<button>`，`aria-label` 用问题原文；三态文字对软底取 `-700` / `-strong` 档过 4.5:1；`prefers-reduced-motion: reduce` 下关闭呼吸 / 旋转 / 脉冲但保留静态描边。
- **用户气泡的可读性**：气泡正文为白字，底色取 `--brand-fill`（品牌实底，契约「保白字 AA」）而不是 `--brand-500`，亮 / 暗分别 **5.59:1 / 4.77:1** 过 WCAG AA；高亮脉冲在气泡上换成「纯外扩涟漪」版本（带 `inset` 内光的通用脉冲会把正文底下那层提亮到瞬时跌破 AA）；这条不变量由 `scripts/theme-contrast-check.py` 对亮暗两块同时卡门禁。

### 敏感工具安全确认

以下工具操作前会弹出确认对话框（**5 分钟超时自动拒绝**，由 `reactConfig.toolConfirmationEnabled` 总开关控制，关闭后敏感操作直接放行）：

- `manage_tab`（close action）、`download_file`、`manage_cookies`、`manage_storage`（clear action）
- `agent_file`（delete action）、`agent_exec`

> 💡 **并发排队与计时起点**：并行子任务可能同时请求多条确认 / 澄清。两类弹窗共用一个**单模态闸门**，按 FIFO **逐条呈现**（同一时刻只弹一个，当前弹窗上会告知「另有 N 条在排队」），不会出现后一个遮住前一个、点不到按钮的情况。超时倒计时只在某条**真正显示出来**之后才开始消耗 —— 排队中的请求不计时，因此不存在「没机会拒绝就被判拒」。面板关闭或弹窗无法送达时按 **fail-closed** 立即拒绝，不白等 5 分钟。

Agent 命令执行三级安全：
1. **黑名单**（始终禁止）：`rm -rf /`、`mkfs.*`、fork 炸弹、curl-to-shell 管道等
2. **灰名单**（需确认）：`sudo`、`npm install -g`、`chmod -R 777`、`git push --force` 等
3. **白名单**（直接放行）：常规命令

### Agent 核心特性

- **CLI 命令丰富**：支持 `start`/`stop`/`restart`/`status`/`paircode`/`config` 等命令，`aha` 快捷别名
- **后台守护进程**：`start --background` / `-b` 后台启动模式，终端立即返回，不阻塞会话
- **进程管理**：PID 文件管理 + 进程树追踪与检索（命令全链路清理），优雅关闭机制，防止重复启动
- **配对认证**：6 位动态码 + extensionId 配对，生成 Bearer Token
- **路径沙箱**：`realpathSync` 解析符号链接，前缀匹配白名单路径
- **命令安全**：环境变量白名单（约 40 个），`TERM=dumb` 禁用互动
- **脚本保护**：写入 `.sh`/`.py`/`.js` 等自动去除执行权限
- **大小限制**：请求体 10MB，单文件 50MB
- **文件回收站**：删除文件默认软删除至 `~/.ai-helper-agent/.trash/`，7 天自动清理，支持恢复
- **在线更新**：支持通过 API 在线重启和自动更新 Agent（`/api/agent/restart`、`/api/agent/update`）
- **多格式预览**：服务端支持 xlsx 解析预览，浏览器端支持 PDF/Word/图片预览
- **审计日志**：双通道输出（终端格式化 + 文件 JSON Lines），按日命名，自动清理 30 天
- **多级健壮性保护**：请求级异常捕获、URL 解析保护、全局兜底、文件 I/O 保护、进程管理保护
- **快速搜索**：fd（文件名）+ ripgrep（内容）原生加速，不可用时自动回退 Node.js 实现
- **本地知识库 (RAG)**：依赖自动检测/安装与启动自动恢复；向量 + 关键词混合检索（支持中英混合关键词）；停用的知识库不参与自主检索，但 @ 手动引用仍可用

### Skill 系统（Agent 端）

| 类型 | 定义格式 | 执行方式 | 用途 |
|------|----------|----------|------|
| **Workflow Skill** | JSON/YAML | 直接执行 | 自动化流程，按步骤执行，支持条件跳过 |
| **Agent Skill** | SKILL.md | AI 自主调用 | 知识沉淀，在对话中触发 |

导入方式：JSON 上传 / 在线编写 Markdown / Zip 包（含辅助资源）/ URL 下载

### MCP 协议（Agent 端）

- **MCP Client**：基于 JSON-RPC 2.0，stdio 传输
- **自动发现**：连接后自动获取工具列表
- **多 Server**：同时连接多个，工具自动合并
- **动态注入**：每次推理前自动同步最新工具列表

## 状态管理设计

### 双导出 Proxy 模式

[state.js](file:///Users/xiweicheng/Documents/trae_projects/ai-helper/src/side_panel/state.js) 采用独特的双导出 Proxy 模式：

```js
// 两种导入方式指向同一数据
import state from './state.js';      // state.messageHistory
import { messageHistory } from './state.js'; // 直接解构
```

通过 Proxy 的 getter/setter 代理到顶层 `let` 绑定，确保所有模块共享同一份状态，无需框架。支持 80+ 个状态字段，包括图片输入、文件附件、技能选择、MCP 服务选择等。

### 数据持久化策略

| 数据类型 | 存储位置 | 说明 |
|----------|----------|------|
| 扩展配置 | `chrome.storage.local` | API Key、ReAct 参数、模型、图片识别、界面主题（`appTheme`）等 |
| 对话会话 | IndexedDB (`ai-helper-db`) | 活跃会话 + 归档会话 |
| 侧边栏待办 | IndexedDB (`todos`) | 标题/状态/备注/截止日/排序/优先级/链接/完成前状态 |
| UI 原型 | IndexedDB | 按会话关联 |
| 工具栏配置 | `chrome.storage.local` | 工具列表、排序、域名屏蔽 |
| 输入历史 | `chrome.storage.local` | 去重自动管理 |
| 跨重启消息 | `chrome.storage.session` | SW 重启恢复、后台任务持久化 |
| 记忆向量配置 | Agent `config.json` 的 `memoryEmbedding` | 由选项页「记忆」Tab 读写，不在扩展存储里 |
| 长期记忆与派生向量 | Agent `memory/` 目录（`global-memory.json` / `memory-vectors.json`） | 记忆条目是唯一真源，向量文件可丢可重建 |

### IndexedDB 数据库设计

`ai-helper-db` (v7)，九个对象存储：

| Store | 用途 |
|-------|------|
| `sessions` | 活跃会话（索引：updatedAt） |
| `activeSession` | 当前活跃会话 ID |
| `archivedSessions` | 已归档会话（索引：createdAt） |
| `uiPrototypes` | UI 原型（索引：createdAt, sessionId） |
| `tokenStats` | Token 使用统计（索引：timestamp, sessionId） |
| `reactCheckpoints` | ReAct Checkpoint 断点（7 天 TTL 自动过期） |
| `bookmarks` | 消息收藏（索引：sessionId, pinned, createdAt） |
| `scheduledTasks` | 定时任务（索引：nextRunAt, enabled） |
| `todos` | 侧边栏待办（索引：status, createdAt） |

支持自动从事务失败恢复及旧版 `chrome.storage.local` 自动迁移。

## 常见问题

**Q: 扩展加载后图标不显示？**
确保 `chrome://extensions/` 中「开发者模式」已开启，并选择了正确的扩展目录。

**Q: 侧边栏打不开？**
Chrome 版本需 >= 114，低版本不支持 Side Panel API。

**Q: 工具调用不生效？**
检查选项页中工具是否启用，部分工具需要特定网站权限。Agent 工具需要先完成配对连接。

**Q: 构建后文件名带有 hash？**
`scripts/fix-build.js` 会自动将 hash 文件名重命名为固定文件名，无需重新加载。

**Q: 如何开启图片识别？**
在选项页「基础」Tab 中开启「启用图片识别功能」开关，可选配独立的 Vision API Base/Key/Model。

**Q: 如何上传文件进行问答？**
直接粘贴或拖拽文件到输入区域，支持 PDF/Word/Excel/文本等格式。有 Agent 时优先上传至工作目录。

**Q: 如何连接本地 Agent？**
```bash
# 全局安装（推荐）
npm install -g ai-helper-agent && ai-helper-agent start
# 或本地启动
cd agent && npm install && npm start
```
然后在扩展选项页「Agent」标签页中输入终端显示的配对码。

**Q: 如何添加 MCP 工具？**
选项页 →「工具箱」Tab → 添加 MCP 服务器 → 填写命令和参数 → 连接。工具会自动注册到系统中。

**Q: 如何导入/导出对话？**
侧边栏输入框下方点击「导出」按钮，可选择多个会话批量导出。导入通过文件选择器完成。

**Q: Agent 命令执行失败？**
确认代理服务正在运行（`npm start`），检查 `~/.ai-helper-agent/config.json` 中的 `allowedPaths` 是否包含目标路径。

**Q: 如何让 Agent 在后台运行？**
使用 `ai-helper-agent start -b` 或 `aha start -b` 后台启动模式。可用 `ai-helper-agent stop` 停止，`ai-helper-agent status` 查看状态。

**Q: Agent 操作有日志记录吗？**
有的。所有文件读写、命令执行、安全事件都会记录审计日志，位于 `~/.ai-helper-agent/logs/`，JSON Lines 格式，保留 30 天。可通过 `/api/logs` 查询。
