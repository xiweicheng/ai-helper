引言 ​

本文件系统性梳理 Agent 端的 Skill 技能系统，覆盖以下主题：

  • 技能定义格式：SKILL.md 文件结构、元数据字段、参数规范与执行上下文。
  • Markdown 技能加载器：文件扫描、YAML frontmatter 解析、正文处理、资源扫描与导入导出。
  • 技能执行框架：步骤 DAG、拓扑排序并行执行、条件分支、超时控制、结果聚合。
  • 模板引擎：变量插值、对象递归渲染、条件逻辑。
  • 注册表与依赖管理：Workflow 与 Agent 两类技能的统一注册、启用/停用持久化、内置种子技能。
  • 与 MCP 协议的集成：Skill 与 MCP 的边界、组合方式与最佳实践。
  • 开发指南：从简单文本处理到复杂业务流程自动化，含调试技巧与性能优化建议。

项目结构 ​

Agent 端 Skill 子系统位于 agent/src/skill，包含加载、执行、模板、注册等模块；Chrome 扩展侧通过工具定义暴露 agent_skill 能力，由 background 工具执行器桥接到 Agent 服务。MCP 子系统独立于 Skill，但可在对话中协同使用。

核心组件 ​

  • Markdown 技能加载器：负责 SKILL.md 扫描、frontmatter 解析、正文清洗、资源扫描、Zip/URL 导入与安全校验。
  • Workflow/Agent 加载器：统一加载 JSON/YAML Workflow 与 Agent SKILL.md，并输出标准化技能定义。
  • 技能注册表：维护内存中的技能映射、启用状态持久化、内置种子技能、查询与执行入口。
  • 技能执行引擎：解析步骤 DAG、拓扑排序并行执行、条件 with when、模板渲染、工具调用封装、超时与部分成功处理。
  • 模板引擎：支持 {{var}} 插值、{{#if}}...{{/if}} 条件、对象递归渲染。
  • 扩展端工具桥接：agent_skill 工具定义与 background 执行器，将 AI 的工具调用路由到 Agent 技能。
  • MCP 工具注册表：独立于 Skill，提供第三方工具发现与调用，可与 Skill 协同工作。

详细组件分析 ​

Markdown 技能加载器 ​

职责：

  • 扫描 skills 目录下子目录的 SKILL.md。
  • 解析 YAML frontmatter（name/description/version/enabled 等）。
  • 清理正文标题行，保留 fullPrompt 与 prompt。
  • 扫描 scripts/templates/assets/references 等资源目录，过滤构建产物与语言包缓存。
  • 支持 Zip 导入（纯 JS ZIP 解压，路径穿越防护）、URL 下载（HTTP/HTTPS，重定向限制与主机白名单）。
  • 名称校验与目标路径越界检查，避免命令注入与路径穿越。

关键流程（Zip 导入）：

flowchart TD

ParseUrl --> HostCheck["DNS 解析与内网地址拦截"]
HostCheck --> Download["下载 ZIP限大小、限重定向次数"]
Download --> Extract["纯 JS 解压 ZIP"]
Extract --> FindMd["查找顶层目录或根目录中的 SKILL.md"]
FindMd --> SanitizeName["名称安全校验"]
SanitizeName --> PathGuard["目标路径越界检查"]
PathGuard --> CopyDir["复制至 skills 目录"]
CopyDir --> Reload["重新加载技能"]
Reload --> End(["结束"])

Workflow/Agent 加载器 ​

职责：

  • 加载 Workflow 技能（JSON/YAML），进行基础 Schema 校验（name/description/steps 等）。
  • 加载 Agent 技能（通过 markdown-loader）。
  • 统一输出 type=workflow 或 type=agent 的技能定义。
  • 提供保存、删除、种子写入 skill-creator 的能力。

要点：

  • Workflow 默认 enabled=true，steps 必须为数组且每个 step 需 id 与 tool。
  • Agent 技能通过 loadAllMarkdownSkills 合并进统一列表。
  • seedSkillCreator 在首次运行或版本升级时写入内置 skill-creator。

技能注册表 ​

职责：

  • 初始化时加载文件系统技能与内置种子技能。
  • 恢复内置技能与用户手动停用的技能状态（持久化到 JSON 文件）。
  • 提供 getSkillList/getSkill/runSkill/getAgentSkillPrompts/getAgentSkillPrompt/importSkill/removeSkill/toggleSkill/reloadSkills 等 API。
  • 对 Agent 技能提供三级模糊匹配（精确 name、目录名、归一化 slug）。

关键点：

  • disabled_skills.json 与 builtin_skills_state.json 分别记录用户停用与内置启用状态。
  • toggleSkill 优先更新持久化文件，再尝试回写源文件（best-effort）。
  • getAgentSkillPrompts 生成注入 System Prompt 的轻量描述，便于 AI 按需加载完整内容。

模板引擎 ​

功能：

  • 变量插值：{{variable}}，支持点号路径 a.b.c。
  • 条件渲染：{{#if variable}}...{{/if}} 与取反 !variable。
  • 对象递归渲染：renderObject 遍历字符串值进行模板替换。

复杂度：

  • 单次模板渲染 O(n)，n 为模板长度；对象递归渲染 O(m)，m 为对象节点数。

MCP 协议集成 ​

  • MCP 工具注册表独立于 Skill，负责连接多个 MCP Server，扁平化工具列表，并提供 callMcpTool。
  • Skill 与 MCP 的区别：Skill 是预定义工作流或 AI 自主调用的指令集；MCP 是动态工具生态。
  • 两者可组合：在 Workflow 或 Agent 步骤中调用 MCP 工具，实现外部系统交互。

性能与资源管理 ​

  • 执行并发：DAG 同层步骤并行执行，提升吞吐；通过 ready 队列与 completed 集合避免重复执行。
  • 超时与清理：EXECUTION_TIMEOUT 防止长时间阻塞；activeExecutions 定期清理已完成/错误任务，上限 MAX_ACTIVE_EXECUTIONS。
  • 资源扫描：scanResources 排除 node_modules、pycache、dist 等目录，减少无效文件统计。
  • 下载限制：MAX_SKILL_DOWNLOAD_SIZE 限制 ZIP 大小，重定向最多 5 次，每次重定向均校验主机。
  • 模板渲染：对象递归渲染避免深层嵌套导致的重复计算；条件渲染先于变量插值，减少无用模板展开。

故障排查指南 ​

常见问题与定位：

  • 技能未加载：检查 skills 目录是否存在、SKILL.md 是否有效、frontmatter 是否缺失必要字段。
  • 导入失败：确认 ZIP 结构包含顶层目录或根目录 SKILL.md；名称仅允许字母数字下划线短横线；目标路径未越界。
  • 下载失败：URL 协议仅限 http/https；主机非内网/环回；重定向次数不超过限制；响应体不超过 20MB。
  • 执行失败：检查 when 条件是否为真；参数类型是否正确；路径/命令是否被安全策略拒绝；命令灰名单需要确认。
  • 状态不一致：toggleSkill 优先更新 disabled_skills.json；若源文件写入失败不影响状态。

结论 ​

Skill 系统通过 Markdown 驱动的 Agent 技能与 JSON/YAML 驱动的 Workflow 技能，形成“确定性自动化 + AI 自主决策”的双轨能力。加载器保证安全与健壮性，执行引擎提供并行与条件控制，注册表统一管理生命周期与状态。与 MCP 协议互补，Skill 聚焦“怎么做”，MCP 提供“用什么工具做”。开发者可基于现有示例快速构建从简单文本处理到复杂业务流程自动化的技能。

开发最佳实践 ​

  • 明确何时使用：在 SKILL.md 的“何时使用”段落给出触发场景与关键词。
