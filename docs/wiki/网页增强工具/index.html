引言 ​

本文件面向“网页增强工具”的开发者与使用者，系统性说明扩展端（Chrome Manifest V3）与本地 Agent 端的协作方式，并重点聚焦以下能力：

  • 信息提取：文本与结构化数据、表格、链接、表单、图片、元数据、JSON-LD/Microdata、iframe 内容、页面内搜索。
  • 交互操作：元素定位与点击、表单填写与提交、滚动与导航控制、键盘输入模拟、弹窗处理、等待稳定。
  • 截图与图像处理：全页截图、区域选择截图、图片预览与压缩、视觉识别集成。
  • Shadow DOM 穿透与跨域 iframe 访问策略。
  • 快照编排与 ref 跨帧路由，支撑 query_elements → interact_element/fill_form/select_dropdown 的稳定引用。
  • 性能优化、常见问题排查与最佳实践。

本项目为双进程架构：扩展端（src/）+ 独立本地代理端 Agent（agent/src/server.js）。两端版本号同步，当前以 2.3.1 为准。扩展端通过本地 HTTP/WebSocket 调用 Agent 的文件读写、命令执行、长期记忆与 RAG 能力；Agent 源码修改后需重启进程才生效。

项目结构 ​

围绕“网页增强工具”，关键代码分布在 content 脚本（页面侧）、background 工具定义与编排器（后台侧）、共享渲染器（快照输出），以及 side panel 的图片处理入口。

核心组件 ​

  • 信息提取工具（content/page-extract.js）
    • 元数据：title/description/keywords/author、Open Graph/Twitter Card、canonical、JSON-LD、Microdata。
    • 链接：a/img 链接，支持内外链过滤、可选包含图片。
    • 表单：input/textarea/select 字段结构、必填、占位符、选项列表、生成选择器。
    • 图片：尺寸过滤、背景图抽取、批量下载（限前若干张）。
    • Markdown/JSON：页面转 Markdown、结构化 JSON（tables/lists/jsonLd/articles/microdata）。
    • iframe：同源可访问时提取 title/text/htmlLength，支持嵌套。
    • 搜索：plain/regex 模式、大小写敏感、上下文片段、可选 Range 高亮。
  • 交互操作工具（content/interaction-tools.js）
    • 点击：deepQuerySelector + autoWaitAfterAction，自动检测 URL/DOM 变化。
    • 表单填写：text/select/checkbox/radio/contenteditable，绕过 React 受控组件。
    • 滚动：top/bottom/coordinates/selector，边界判定与无进展标记。
    • 可见性检查：display/visibility/opacity/clip-path/视口判定。
    • 等待：appeared/disappeared/visible/hidden，轮询超时。
    • 键盘输入：InputEvent/KeyboardEvent，兼容富文本编辑器。
    • 文件上传：DataTransfer + Blob/File，base64 解码回退。
    • 按文本点击：遍历可交互元素，精确/包含匹配，诊断错误原因。
    • 下拉选择：原生 select 与自定义下拉（div+ul+li），超时匹配。
    • Storage 管理：session/localStorage get/set/remove/clear。
  • Shadow DOM 与 iframe 穿透（content/shadow-dom-utils.js）
    • deepQuerySelector/All：优先 Shadow DOM，再当前根，跳过跨域 iframe。
    • deepGetText/Html：合并 body.innerText/shadow tree/iframe 内容。
    • 选择范围/坐标：跨 iframe 偏移修正。
    • 监听器：selectionchange 多 root 附加/移除。
  • 交互元素查询与快照（content/page-interaction.js + shared/page-snapshot-renderer.js）
    • 可交互元素遍历、角色推导、名称解析、属性序列化。
    • 叠加层（dialog/popover/menu/listbox）分区，打开层子树独立。
    • ref 编号：WeakMap 跨快照复用，失效时 selector 兜底重查。
    • renderSnapshot：统一渲染入口，分页/预算/帧区块头/截断提示。
  • Background 工具定义与编排（background/tools/browser-tools.js + snapshot-orchestrator.js）
    • browser-tools.js：interact_element/scroll_to/wait_element/handle_dialog/fill_form/keyboard_input/file_upload/select_dropdown/page_content/extract_data/query_elements/search_in_page/iframe_content/scroll_collect 等工具 Schema。
    • snapshot-orchestrator.js：webNavigation 帧枚举 → 并行定向收集各帧 ops → frame 节点三重对应 → 全局 ref 编号表 → 渲染 frames[]。
    • 跨帧路由：shouldRouteRefTool/routeSingleRefTool/routeFillForm，失败时提供最近有效 ref 建议。
  • 工具执行与辅助（background/tool-executor.js + tool-helpers.js）
    • 工具分发、MCP/RAG 动态注册、网络访问校验、截图下载、视觉识别 API 调用。
    • tryParseToolArgs：两阶段解析 + 位置引导修复 + 尾随逗号/未引号字符串/括号补全。
    • normalizeToolResult：统一 {success,content,...} 返回格式。
    • sendToContentScriptWithRetry：失败自动注入 content script 并重试。
  • 截图与图像处理（background/tool-screenshot.js + side_panel/image-helpers.js）
    • 全页截图：CAPTURE_TAB → dataUrl → 压缩/预览。
    • 区域截图：START_REGION_SELECTION → rect → CAPTURE_TAB → Canvas 裁剪 → 预览。
    • 下载：triggerScreenshotDownload(dataUrl, format)。

详细组件分析 ​

信息提取工具（page-extract.js） ​

  • 元数据提取
    • 读取 meta[property|name]、og:、twitter:、article:*、canonical。
    • 解析 JSON-LD（支持 @graph 数组）与 Microdata（itemscope/itemprop）。
  • 链接提取
    • a[href]/img[src]，区分内外链，可选 includeImages。
  • 表单提取
    • input/textarea/select，记录 name/id/type/placeholder/required/options，生成选择器。
  • 图片提取
    • 尺寸过滤、背景图抽取、可选下载（限制数量）。
  • Markdown/JSON 转换
    • 递归遍历 DOM，输出 Markdown；或结构化 tables/lists/jsonLd/articles/microdata。
  • iframe 内容
    • 仅同源可访问，返回 selector/url/title/textContent/htmlLength，支持嵌套。
  • 页面内搜索
    • plain/regex 模式，caseSensitive，contextLength，maxResults，highlight（Range 包裹，SEC-08）。

交互操作工具（interaction-tools.js） ​

  • 点击与自动等待
    • clickElement(selector) 先 deepQuerySelector，点击后 autoWaitAfterAction，报告 URL/DOM 变化。
  • 表单填写
    • fillForm(fields)：text/select/checkbox/radio/contenteditable；React 受控组件用 setNativeValue。
  • 滚动与导航
    • scrollToPosition(options)：top/bottom/coordinates/selector，边界判定与 moved=false 标记。
  • 可见性与等待
    • isElementTrulyVisible(el)：display/visibility/opacity/尺寸/视口。
    • waitForElement(selector, state, timeout)：appeared/disappeared/visible/hidden。
  • 键盘输入
    • keyboardInput({key,text,...})：InputEvent/KeyboardEvent，富文本 execCommand 回退。
  • 文件上传
    • fileUpload(selector, fileName, fileContent, fileType)：Blob/File/DataTransfer。
  • 按文本点击
    • clickByText(text, options)：遍历可交互元素，精确/包含匹配，诊断 textNotFound/textHidden/textNotClickable。
  • 下拉选择
    • selectDropdown(triggerSelector, optionText, optionSelector, timeout)：原生 select 与自定义下拉。
  • Storage 管理
    • manageStorage({action, storage, key, value})：get/set/remove/clear。

性能与优化建议 ​

  • 避免重写 innerHTML：搜索高亮使用 Range.surroundContents（SEC-08），保留事件监听与框架虚拟 DOM 关联。
  • 控制快照字符预算：renderSnapshot 使用 maxChars 预算，容器行盲扣预算，避免大页面阻塞。
  • 限制 iframe 展开：MAX_VISIBLE_FRAMES=20，MAX_FRAME_DEPTH=3，超限计入 excludedIds。
  • 自动等待稳定：autoWaitAfterAction 最小等待 + 连续稳定计数，减少无效阻塞。
  • 参数解析鲁棒性：tryParseToolArgs 多阶段修复，防止 LLM 输出异常导致执行失败。
  • 跨帧路由失败建议：translateRoutedResult 提供最近有效 ref 建议，降低模型重试成本。
  • 图片处理：Canvas 裁剪考虑 devicePixelRatio，压缩后再附加预览，减少内存占用。

故障排查指南 ​

  • 无法访问标签页或系统页面
    • 现象：cannotAccessTab/cannotUseOnSystemPage。
    • 排查：确认 tabId 有效且非 chrome:// / about: / chrome-extension://。
  • Content Script 注入失败
    • 现象：injectContentScriptFailed。
    • 排查：manifest.content_scripts 配置正确；sendToContentScriptWithRetry 已自动注入并重试。
  • 元素定位失败
    • 现象：elementNotFoundBySelector/invalidRef。
    • 排查：优先使用 query_elements 返回的 ref；若失效，重新调用 query_elements。
  • 跨域 iframe 不可访问
    • 现象：iframe accessible=false。
    • 排查：仅同源可访问；跨域需后端代理或同域部署。
  • 表单填写不生效（React/Vue）
    • 现象：value 未更新。
    • 排查：使用 setNativeValue 或 keyboard_input；避免直接赋值。
  • 截图下载失败
    • 现象：downloadTriggerFailed。
    • 排查：检查 downloads 权限与浏览器默认下载目录。
  • 视觉识别 API 超时或为空
    • 现象：screenshotAnalysisTimeout/screenshotAnalysisEmpty。
    • 排查：检查 imageApiBase/apiKey/modelName/streamEnabled；重试或更换模型。

结论 ​

本“网页增强工具”以 content 脚本为核心，结合 background 的工具定义与快照编排器，实现了从信息提取、交互操作到截图与图像处理的完整能力闭环。通过 Shadow DOM 穿透、iframe 同源访问、ref 跨帧路由与统一快照渲染，系统在复杂现代 Web 应用中具备较强的稳定性与可扩展性。配合 tool-executor 的参数解析鲁棒性与注入重试机制，显著提升了自动化操作的可靠性。建议在大规模页面中合理使用分页与字符预算，优先使用 query_elements 的 ref 进行交互，并在跨域场景下采用后端代理方案。

附录：使用示例与最佳实践 ​

  • 网页数据抓取
    • 步骤：调用 extract_data(dataType=metadata/links/forms/images/table)，按需传入 selector/filterType/includeHeaders/format/minWidth/minHeight/maxResults。

  • 自动化操作
    • 步骤：先 query_elements 获取 ref，再 interact_element(action=click/hover/type) 或 fill_form(fields=[{ref,value}] )。
    • 参考路径：src/background/tools/browser-tools.js#L3-L158、src/content/page-interaction.js#L51-L152。
  • 页面分析
    • 步骤：page_content(format=text/html) 获取全文或 HTML；search_in_page(query, mode=plain/regex, highlight=true) 定位关键词。
    • 参考路径：src/background/tools/browser-tools.js#L231-L333、src/content/page-extract.js#L665-L800。
  • 截图与图像识别
    • 步骤：side_panel 触发 captureFullPageScreenshot/captureRegionScreenshot，background 触发 screenshot 下载；可选调用 analyzeScreenshotWithVision 进行视觉分析。

  • 最佳实践
    • 优先使用 query_elements 的 ref 定位元素，避免脆弱 CSS selector。
    • 对 React/Vue 应用，使用 setNativeValue 或 keyboard_input 填写表单。

    • 跨域 iframe 不可访问时，改用后端代理或同域部署。
    • 截图后如需分析，确保配置 imageApiBase/apiKey/modelName/streamEnabled。
