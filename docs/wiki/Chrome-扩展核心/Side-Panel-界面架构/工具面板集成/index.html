引言 ​

本文件面向“工具面板集成”的完整技术文档，覆盖以下目标：

  • 工具面板整体架构、工具分类、动态加载与状态管理。
  • 内置工具的注册机制、定义格式、参数验证与执行框架。
  • MCP 工具集成：远程工具发现、协议适配、错误处理与服务级开关。
  • RAG 知识库配置界面：知识库选择、检索参数调整与结果预览。
  • Skill 技能系统的面板集成：列表展示、执行控制与结果输出。
  • 工具权限控制：安全检查与用户确认流程。
  • 工具配置的持久化存储与版本迁移策略。

本项目采用双进程架构：Chrome 扩展端（Manifest V3）与独立本地代理端 Agent（Node.js）。两端通过本地 HTTP/WebSocket 通信；Agent 源码修改后必须重启进程，新接口才生效。

项目结构 ​

工具面板相关代码分布在三个层次：

  • 侧边栏 UI：工具弹窗、分类筛选、MCP/RAG/Skill 入口。
  • 选项页工具箱：MCP 服务器管理、Skill 管理、RAG 能力探测与安装引导、知识库管理。
  • Background 执行层：工具定义、动态注册、执行调度与安全校验。
  • Agent 服务端：MCP 注册表、Skill 加载器、RAG 能力检测与索引。

核心组件 ​

  • 工具面板（Side Panel）：负责工具弹窗渲染、分类筛选、搜索、MCP 服务分组、RAG 工具缓存、全局开关与 Agent 连接状态感知。
  • 选项页工具箱：统一入口，聚合 MCP 服务器管理、Skill 管理与 RAG 能力探测；提供全局开关与统计计数。
  • Background 执行层：集中维护工具定义、动态注册（MCP/RAG）、执行映射、并行与确认标记、安全校验与审计。
  • Agent 服务端：MCP 注册表管理多客户端连接与工具调用；Skill 加载器扫描并校验 Workflow/Agent 技能；RAG 能力检测与安装引导。

关键职责边界：

  • 侧边栏仅做展示与轻量交互，不直接执行业务逻辑。
  • 选项页负责配置与远端 API 调用，Background 负责工具注册与执行。
  • Agent 端暴露 REST 接口，供扩展端查询与操作。

详细组件分析 ​

工具面板（Side Panel） ​

  • 工具分类与排序：使用 CATEGORY_ORDER 与 BUILTIN_TOOLS 快照，补充 'mcp' 与 'knowledge' 动态分类。
  • 动态加载：
    • MCP 工具：优先从 Background 获取，否则回退 chrome.storage.local.mcpTools。
    • RAG 工具：从 storage.ragTools 同步，由 Background 在注册/卸载时更新。
  • 状态管理：
    • 全局开关：mcpEnabled、skillsEnabled。
    • 工具启用：state.enabledTools。
    • MCP 服务关闭列表：state.mcpClosedServers。
    • 助手排除列表：activeAgentMcpExcludedServerIds。
  • 交互：
    • 分类折叠、全选/取消全选、搜索过滤。
    • MCP 服务行展开只读工具列表。
    • 预筛选与敏感操作确认开关状态实时同步。

选项页工具箱（Options Toolbox） ​

  • 统一入口：refreshToolbox 并行加载 MCP 与 Skill，渲染列表并更新统计。
  • MCP 管理：
    • 增删改查、连接/断开、启用/禁用、环境变量与请求头编辑。
    • 传输方式支持 stdio、SSE、Streamable HTTP、WebSocket。
    • 添加/编辑成功后通知 Background 重新加载 MCP 工具。
  • Skill 管理：
    • 列表展示（Workflow/Agent），启用/停用、删除、运行、导入（JSON/Markdown/Zip/URL）。
    • 参数解析与输入弹窗，执行结果分步展示。
  • RAG 能力探测：
    • 读取 /api/status 的 ragAvailable 与 nodeVersion。
    • 未就绪时展示安装引导与进度轮询，完成后通知 Background 重新注册 RAG 工具。

MCP 工具集成 ​

  • 远程工具发现：Background 调用 AgentClient.getMcpTools() 与 getMcpServers()，构建 RAW_TOOLS/BUILTIN_TOOLS/TOOL_EXECUTION_MAP/TOOL_HANDLERS。
  • 协议适配：支持多种传输方式（stdio/SSE/streamableHttp/websocket），由选项页表单配置 env/headers。
  • 错误处理：
    • 全局开关关闭时跳过加载。
    • 禁用服务器工具被过滤。
    • schema 压缩（限制 description 长度、嵌套深度、参数数量）。
    • 服务级 deny-list（弹窗层关闭 + 助手编辑器排除）。
  • 服务级开关：
    • 弹窗层 mcpClosedServers 与服务是否被助手排除 activeAgentMcpExcludedServerIds 共同决定最终开放状态。
    • 强制下发：会话内可通过手动指定强制包含某服务的工具。

RAG 知识库工具与配置界面 ​

  • 工具定义：RAG_TOOLS 包含 knowledge_search、knowledge_ingest、knowledge_list，仅在 ragEnabled=true 且 agent /api/status ragAvailable=true 时动态注册。
  • 配置界面：
    • 门控：Agent 未连接 / RAG 总开关未启用 / 代理端能力未就绪。
    • 知识库列表：新建/编辑/删除/启停/导入文档/文档管理/检索测试。
    • 向量配置：本地或 OpenAI 兼容模式，支持 endpoint/apiKey/modelName/dimensions 测试连通性与自动维度填充。
    • 导入：支持文件/文本/URL，分块参数可调整，进度阶段可视化。
    • 检索：默认 topK/threshold，支持集合 ID 限定检索。

故障排查指南 ​

  • 工具弹窗无数据：
    • 检查 Background 是否已加载 MCP/RAG 工具缓存（storage.mcpTools/storage.ragTools）。
    • 确认全局开关 mcpEnabled/skillsEnabled 与 Agent 连接状态。
  • MCP 工具不可用：
    • 检查服务是否被禁用（servers[].enabled=false）或弹窗层关闭（mcpClosedServers）。
    • 检查助手编辑器排除列表（activeAgentMcpExcludedServerIds）。
  • RAG 功能不可用：
    • 检查 /api/status 的 ragAvailable 与 nodeVersion。
    • 若依赖未安装，进入安装引导并轮询 /api/rag/install/status。
  • Skill 执行失败：
    • 检查参数必填项是否填写，查看执行结果弹窗中的步骤状态与错误信息。
  • 命令执行被拒绝：
    • 检查是否需要用户确认（requiresConfirmation），以及网络访问白名单与内网地址策略。

结论 ​

工具面板集成以“侧边栏展示 + 选项页配置 + Background 执行 + Agent 能力”的分层架构实现，具备完善的动态加载、分类管理、权限控制与错误处理机制。MCP 工具以服务级开关与 schema 压缩保障安全与性能；RAG 知识库提供完整的配置界面与安装引导；Skill 系统支持 Workflow 与 Agent 两种形态，并提供参数校验与结果可视化。扩展时可遵循现有模式新增工具类别与动态工具，同时注意 MV3 Service Worker 生命周期约束与 Agent 进程重启要求。
