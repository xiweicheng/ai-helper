引言 ​

本文件面向 UI 主题、国际化、响应式与可访问性，以及侧边栏与配置页的界面实现。文档围绕以下目标展开：

  • 主题系统：CSS 变量 Token 体系、亮/暗/跟随系统三态切换、对比度审计与“白斑”检测。
  • 国际化：扩展端 chrome 消息与运行时 i18n 双通道、多语言字典组织、运行时语言切换与跨环境同步。
  • 响应式：移动端适配、屏幕尺寸断点与布局优化。
  • 可访问性：ARIA 属性、键盘导航、屏幕阅读器兼容与色彩对比度合规。
  • 组件开发指南：样式定制方法、交互模式最佳实践，并给出主题开发与翻译维护的具体示例。

核心组件 ​

  • 主题 Token 与运行时：通过 data-theme 在 <html> 上切换亮/暗；所有颜色使用语义化 Token，避免硬编码色值。
  • 国际化运行时：提供 t(key, params)、setLanguage、initI18n、applyI18n，支持 DOM 属性驱动文案填充。
  • 侧边栏与配置页：分别由 side_panel/index.js 与 options/index.js 初始化主题与语言，并订阅变更以刷新 UI。
  • 后台入口：注册翻译、处理快捷键与侧边栏可见性，同时作为扩展消息中枢。

详细组件分析 ​

主题系统与 Token 体系 ​

  • Token 分层：表面、文本、品牌、边框分隔、状态、Toast、蒙层阴影等，均使用语义命名。
  • 亮/暗双主题：:root 定义亮色值，html[data-theme="dark"] 覆盖暗色值，确保 WCAG AA 对比度。
  • 固定不翻转 Token：如纸面语义、终端代码块背景在两主题下保持一致。
  • 原生控件统一：checkbox/radio/range/color/progress 使用品牌强调色。
  • Markdown 暗色覆盖：针对第三方库写死亮色的类进行暗色回退。

主题审计与对比度门禁 ​

  • 动态审计（Playwright）：加载 dist 构建产物，将侧边栏与配置页切换到暗色，遍历已渲染元素计算前景/背景对比度，检测“白斑”（近纯白大块背景），输出违规清单。
  • 静态审计（Python）：解析 theme.css 中暗色 Token，按文本 4.5:1、图形 3:1 阈值校验，装饰性分隔仅 INFO 提示。

国际化支持与运行时切换 ​

  • 运行时 i18n：i18n.js 提供 t(key, params)、setLanguage、subscribe、registerTranslations、initI18n、applyI18n。
  • 语言包组织：locales/zh.js、locales/en.js 按模块分组，key 用点分访问；侧边栏与后台脚本可按需追加翻译。
  • Chrome 扩展消息：_locales/*/messages.json 用于扩展名称、描述与命令文案，由 chrome.i18n 提供。
  • 运行时语言切换：options/index.js 初始化语言选择器，调用 setLanguage 并触发 applyI18n() 刷新 DOM。

  • ARIA 属性：applyI18n 支持 data-i18n-aria-label，将翻译文案写入 aria-label，提升屏幕阅读器可读性。

界面组件开发指南 ​

  • 样式定制方法：
    • 所有颜色必须引用 theme.css 中的 Token，禁止硬编码色值。
    • 浮层与菜单使用 --elev-pop / --elev-float / --elev-surface 组合，确保暗色下阴影与描边一致。
    • 表单控件统一继承文字色，避免暗色残留黑字。
  • 交互模式最佳实践：
    • 下拉菜单与子菜单使用 show 类切换显隐，配合 aria-expanded 控制可访问性。
    • 长列表采用虚拟滚动与键盘焦点同步，确保方向键与 Tab 导航体验。
    • Toast 与模态框使用语义化 Token 控制背景与前景，确保对比度达标。

性能与可访问性 ​

  • 性能：
    • 主题切换仅在 resolved 变化时通知订阅者，避免重复渲染。
    • 语言切换通过 subscribe 批量刷新，减少 DOM 操作次数。
    • 侧边栏长列表使用虚拟滚动，降低重排重绘开销。
  • 可访问性：
    • ARIA 属性与键盘导航确保屏幕阅读器与键盘用户可用。
    • 对比度审计确保暗色下文本与图形可读性符合 WCAG AA。

故障排查指南 ​

  • 主题未切换：
    • 检查 appTheme 是否正确写入 storage，data-theme 是否设置为 light 或 dark。
    • 确认 theme.js 的 apply 函数是否被调用且无异常。
  • 语言未刷新：
    • 确认 initI18n 已调用，applyI18n 是否在语言变更后重新执行。
    • 检查 data-i18n* 属性是否正确绑定。
  • 对比度不达标：
    • 运行 scripts/theme-contrast-check.py 检查 Token 对比度。
    • 运行 scripts/theme-dark-audit.mjs 检查实际渲染元素的对比度与“白斑”。
