# 连接本地代理：浏览器里的 AI 能操作你的文件

> 适合平台：知乎、博客园
> 关键词：本地代理、文件操作、命令执行、Chrome 扩展
> 阅读时间：约 6 分钟

---

## 浏览器沙箱：AI 的天花板

浏览器有严格的安全沙箱——这是对的，保护用户安全。但这也意味着，你的 AI 助手被关在了一个笼子里：

- 不能读写你电脑上的文件
- 不能执行终端命令
- 不能跑脚本、装依赖、启动服务

你说"分析一下我项目里的代码复杂度"，AI 只能说"抱歉，我无法访问你的本地文件"。

这不是 AI 的问题，是浏览器架构的限制。

AI Helper 的解决方案是：提供一个可选的 Node.js 本地代理服务（Agent），让浏览器里的 AI 突破沙箱，直接操作你的文件系统和命令行。

## 安装与配对：两分钟搞定

### 安装

全局安装，一行命令：

```bash
npm install -g ai-helper-agent
```

要求 Node.js 18+。安装后会注册 `ai-helper-agent` 命令，还提供了一个快捷别名 `aha`。

如果你不想全局安装，也可以从源码运行：

```bash
cd agent && npm install && npm start
```

### 启动

```bash
# 前台启动（终端显示实时日志，适合调试）
ai-helper-agent start

# 后台启动（守护进程模式，不阻塞终端）
ai-helper-agent start --background
# 或者用快捷别名
aha start -b
```

后台模式特别实用——启动后终端立即返回，Agent 在后台默默运行，不占终端窗口。日常使用推荐这种方式。

### 配对

启动后终端会显示一个 4 位配对码（每 30 秒轮换）。打开 AI Helper 选项页，进入 Agent 配置标签，填入配对码，点击配对。

配对成功后，浏览器扩展和本地代理之间建立 HMAC Token 认证，后续通信不需要再配对。绑定的是 extensionId，换浏览器或重装扩展需要重新配对。

## 解锁的六大能力

连接代理后，AI 突然多了一整套本地操作能力：

### 1. 文件系统操作

AI 可以读写、搜索、删除你指定目录下的文件。所有操作限制在配置的白名单目录内（`allowedPaths`），白名单外的路径一律拒绝。

支持的文件操作包括：读取文件内容、写入文件、列出目录、删除文件/目录、按文件名搜索（fd 加速）、按内容搜索（ripgrep 加速）。

如果系统装了 `fd` 和 `ripgrep`，文件搜索会自动用原生工具加速；没装的话回退到 Node.js 实现，功能一样，只是慢一点。

### 2. 命令执行

AI 可以执行终端命令。这里有个三级安全机制（后面详细讲）：

- **白名单**：普通命令直接执行，比如 `ls`、`cat`、`npm test`
- **灰名单**：需要你确认才能执行，比如 `sudo`、`npm install -g`、`rm -rf`
- **黑名单**：直接拦截，不可绕过，比如 `rm -rf /`、`mkfs`、`curl ... | bash`

命令执行通过 WebSocket 实时输出，你可以在侧边栏看到 stdout 和 stderr 的流式输出，就像在终端里一样。

### 3. 工作区管理

连接代理后，侧边栏会多出一个工作区面板，直接浏览代理工作目录的文件树。支持：

- 目录树导航，点击展开/折叠
- 多选操作（Ctrl/Cmd+Click 多选，Shift+Click 范围选）
- 拖拽移动文件
- 键盘导航（方向键浏览，Enter 打开，Delete 删除）
- 虚拟滚动：文件超过 200 个时自动启用，只渲染可视区域，保证流畅

你可以直接在侧边栏里管理文件，不需要切到 Finder 或终端。

### 4. 文件预览

点击文件可以直接预览，支持多种格式：

| 格式 | 预览方式 |
|------|----------|
| 代码文件 | 语法高亮 |
| PDF | PDF.js 渲染 |
| Word（.docx） | mammoth.js 解析 |
| Excel（.xlsx） | 后端解析为表格 |
| 图片 | 直接显示 |

不用下载到本地再打开，侧边栏里直接看。

### 5. 长期记忆

`agent_memory` 工具让 AI 拥有跨会话的记忆能力。支持三种操作：

- **store**：保存记忆（事实或摘要），支持增删改
- **recall**：按关键词搜索记忆
- **manage**：审查和合并记忆

记忆分两种类型：fact（事实，比如"用户偏好用 TypeScript"）和 summary（摘要，比如"上次对话讨论了架构重构方案"）。事实上限 50 条，摘要上限 20 条，超出后 AI 会自动触发合并和精简。

这意味着 AI 能记住你的偏好和之前的决策，不用每次对话都从头解释。

### 6. 文件回收站

删除文件不是真删——而是软删除到 `~/.ai-helper-agent/.trash/` 目录，保留 7 天。7 天内可以一键恢复，7 天后自动清理。

这个设计很贴心。AI 帮你删文件，万一删错了，还有后悔药。

## 安全设计：该谨慎的地方绝不含糊

让 AI 操作本地文件和执行命令，安全是第一要务。AI Helper 的代理服务在安全上做了多层防护：

### 路径沙箱

所有文件操作限制在白名单目录内。通过 `realpath` 解析真实物理路径，防止符号链接绕过——你建一个软链接指向白名单外的目录，代理不会上当。

某些核心文件（配置文件、配对记录、日志目录）被硬阻止，任何情况下都不可访问。

### 命令三级管控

前面提到的三级机制是核心：

**黑名单**直接拦截：`rm -rf /`、`mkfs`、`dd if=... of=/dev/...`、`> /etc/passwd`、`curl ... | bash`、Fork bomb、Shell 注入（反引号、`$()`）——这些命令碰都不让碰。

**灰名单**需要确认：`sudo`、`npm install -g`、`pip install`、`chmod -R 777`、`rm -rf`、`git push --force`、`shutdown`——AI 要执行这些命令时，会弹窗让你确认。

**白名单**直接执行：其他普通命令。

### 审计日志

所有操作——文件读写、命令执行、安全拦截——全部记录到审计日志。日志格式是 JSON Lines，按日归档（`agent-YYYY-MM-DD.log`），保留 30 天，单文件超过 10MB 自动删除。

你可以通过 API 查询日志，按分类筛选（认证、文件、命令、安全、系统），方便事后追溯。

前台运行时，日志还会以格式化形式实时输出到终端，方便调试时观察 AI 的每一步操作。

## 实际场景：一句话分析代码复杂度

连接代理后，你可以这样和 AI 对话：

> 分析我项目里所有 JS 文件的代码复杂度，列出最复杂的 5 个文件。

AI 会自动：
1. 用 `agent_search` 搜索项目目录下所有 `.js` 文件（ripgrep 加速）
2. 逐个读取文件内容
3. 分析圈复杂度、函数深度、嵌套层级
4. 排序后输出 Top 5 列表，标注问题位置和优化建议

全程不需要你打开终端、不需要跑工具，一句话搞定。

## 在线更新：不用命令行

代理服务支持在线更新。选项页里点击"更新"，代理会执行 `npm update -g ai-helper-agent`，然后自动重启。重启过程是优雅的——先启动新进程接管，再关闭旧进程，端口不中断。

也可以通过 API 触发：`POST /api/agent/update` 一键更新+重启，`POST /api/agent/restart` 只重启不更新。

日常维护完全不需要碰命令行。

## 小结

本地代理服务是 AI Helper 从"浏览器插件"进化为"AI 工作站"的关键一步。它让浏览器里的 AI 突破沙箱限制，获得文件操作、命令执行、长期记忆等本地能力，同时通过路径沙箱、命令分级、审计日志三层安全机制确保安全可控。

如果你还没连过代理，强烈建议试试。装上之后，AI Helper 的能力会上一个完全不同的台阶。
