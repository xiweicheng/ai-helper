# 多智能体协作：创建你的专属 AI 专家团队

> 适合平台：知乎、少数派
> 关键词：多智能体、AI 协作、Chrome 扩展、Agent
> 阅读时间：约 5 分钟

---

## 为什么需要多个 AI？

你肯定遇到过这种情况：让 AI 帮你审查代码，它给你写了一堆产品文案；让它抓取网页数据，它满口分析术语，实际一个表格都没提取出来。

问题不在于 AI 不够聪明，而在于——同一个 AI 很难同时扮演好所有角色。写代码需要严谨的逻辑思维，写文档需要清晰的表达能力，做数据分析需要对数字敏感。如果用一个通用的系统提示词去覆盖所有场景，结果就是哪个都做不好。

AI Helper 的解决方案是：**不要用一个 AI 干所有事，而是组建一个 AI 专家团队。**

---

## 5 个内置模板，开箱即用

AI Helper 内置了 5 个专业助手模板，每个都有独立的系统提示词和工具权限：

| 模板 | 图标 | 擅长领域 |
|------|------|----------|
| 默认助手 | 🤖 | 通用对话，继承全局设置，拥有全部工具 |
| 代码审查专家 | 🔍 | 代码质量、安全漏洞、最佳实践审查 |
| 网页自动化助手 | 🌐 | 表单填写、数据抓取、多步骤页面交互 |
| 数据分析师 | 📊 | 网页数据提取、统计分析、可视化呈现 |
| 文档撰写助手 | 📝 | 技术文档、报告、用户指南撰写 |

注意看每个模板的工具配置——代码审查专家只配备了 7 个工具（页面内容、搜索、文件读写等），网页自动化助手配备了 17 个交互类工具。这不是偷懒，而是刻意为之：**工具越多，上下文越长，AI 越容易跑偏。** 限制每个 Agent 的工具集，反而让它在自己的领域更专注。

## 自定义你的专属 Agent

内置模板只是起点。真正的玩法是自己创建 Agent。

在侧边栏点击 Agent 管理图标，选"创建新 Agent"，你可以为每个 Agent 配置：

- **系统提示词**：定义这个 Agent 的人设、行为准则、回复风格
- **模型**：不同 Agent 可以用不同模型——代码审查用 DeepSeek V4 Pro，文档撰写可以换一个更擅长中文的模型
- **温度**：代码审查设 0.1 保证输出稳定，创意写作设 0.8 增加多样性
- **工具权限**：从 44 个工具里勾选这个 Agent 能用的工具，没勾的一律不注入
- **技能绑定**：指定这个 Agent 能调用哪些 Skill

举个例子，你可以创建一个"前端重构专家"：系统提示词写清楚只关注 React 组件拆分和 Hook 优化，工具只留页面内容提取和文件读写，模型选你用得最顺的，温度压到 0.2。以后每次遇到重构需求，切到这个 Agent 就行，不用每次重新描述需求。

## @ 一键切换，丝滑得像聊天

这是日常使用频率最高的功能。

在输入框里打一个 `@`，立刻弹出 Agent 选择器。用方向键上下选，回车确认，一秒切换。选中的 Agent 名字会显示在输入框里，接下来的对话就由这个 Agent 接管。

你甚至可以在一段对话中途切换 Agent——前半段用数据分析师提取数据，后半段切到文档撰写助手写报告，上下文是连续的。

---

## 子任务分派：让 Agent 之间协作

如果你觉得手动切换还是太麻烦，还有更高级的玩法——子任务分派。

`dispatch_task` 工具允许当前 Agent 把子任务派给其他 Agent 执行。比如你在和默认助手对话时说：

> 帮我做一份竞品调研报告，需要先从三个竞品网站提取功能数据，然后做对比分析，最后写成报告。

默认助手可以：
1. 分派"提取竞品 A 数据"给网页自动化助手
2. 分派"提取竞品 B 数据"给网页自动化助手
3. 分派"提取竞品 C 数据"给网页自动化助手

这些子任务可以**并行执行**，每个子 Agent 有独立的会话 ID，不会互相干扰。等数据都回来后，默认助手再切到文档撰写助手写报告。

整个过程你只说了一句话。

## 实战案例：竞品调研全流程

把上面的能力串起来，看一个完整的竞品调研场景：

**第一步**：打开竞品网站，输入 `@` 切换到网页自动化助手，说"把这个页面的功能列表和定价信息提取出来"。助手自动识别页面结构，提取数据并格式化输出。

**第二步**：`@` 切换到数据分析师，说"对比这三个竞品的功能覆盖度和定价策略，给出优劣势分析"。分析师基于已有上下文数据做对比，输出结构化分析表格。

**第三步**：`@` 切换到文档撰写助手，说"把上面的分析整理成一份竞品调研报告，包含背景、对比矩阵、结论建议"。助手输出一份结构完整、排版清晰的 Markdown 报告。

三个 Agent，三次切换，全程在一个侧边栏里完成。不需要复制粘贴，不需要切换标签页，上下文自动延续。

## 持久化：重启不丢失

所有自定义 Agent 的配置都保存在 `chrome.storage.local` 里——系统提示词、模型设置、温度、工具权限、技能绑定，全部持久化。关浏览器、重启电脑、更新扩展，配置都在。

这意味着你可以慢慢积累自己的 Agent 库：日常工作中遇到新场景，花两分钟创建一个专用 Agent，下次直接 `@` 调用。时间长了，你就有了一支覆盖各种场景的 AI 专家团队。

---

## 小结

多智能体协作的核心思路很简单：**让专业的 AI 做专业的事。** 不要指望一个通用的 AI 解决所有问题，而是根据任务类型选择最合适的 Agent，用工具权限控制它的能力边界，用子任务分派实现协作。

试试看，先从创建一个你自己最常用场景的 Agent 开始。
