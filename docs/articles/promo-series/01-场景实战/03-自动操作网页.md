# 用 AI 自动填写网页表单：测试和运营的效率工具

做测试的朋友应该都经历过：同一个注册表单，要用不同的测试数据跑几十遍。每次手动输入用户名、密码、邮箱、手机号，填完点提交，看结果，再换数据重来。

运营同学也有类似的痛：同一个活动信息要录入到 3 个不同的平台后台，字段差不多，但每个后台的表单结构不一样，手动复制粘贴到怀疑人生。

今天介绍的开源 Chrome 扩展 AI Helper，内置了一整套页面交互工具，能让 AI 直接帮你填表单。

## 页面交互工具集

AI Helper 的 44 个内置工具中，有一组专门做页面交互：

| 工具 | 功能 | 典型用途 |
|------|------|----------|
| `interact_element` | 点击、悬停元素 | 按钮点击、菜单展开 |
| `fill_form` | 批量填表单 | 注册、设置表单 |
| `keyboard_input` | 模拟键盘输入 | 绕过受控组件 |
| `file_upload` | 文件上传 | 头像、附件上传 |
| `select_dropdown` | 下拉选择 | 省份、分类选择 |

这些工具可以组合使用，覆盖绝大多数表单填写场景。

## 具体怎么操作

假设你是一个测试同学，要测试一个注册表单。打开注册页面，在 AI Helper 侧边栏里说：

```
帮我在这个注册表单里填入测试数据：
用户名：testuser001
密码：Test@1234
邮箱：test@example.com
手机号：13800138000
然后点击注册按钮
```

AI Helper 收到指令后，会自动分析当前页面的表单结构，找到对应的输入框，逐个填入数据，最后点击提交按钮。整个过程你只需要看着它操作。

如果表单有下拉选择（比如选择省份），它会调用 `select_dropdown`。如果需要上传头像，它会调用 `file_upload`。AI 会根据表单的实际结构自动选择合适的工具。

## 技术亮点：这些场景也能搞定

### React 受控组件

很多现代前端框架（React、Vue）使用受控组件，直接修改 input 的 value 属性不会触发 onChange 事件，导致表单提交时数据是空的。

AI Helper 的 `keyboard_input` 工具通过模拟真实键盘事件来解决这个问题。它不是直接设置 value，而是模拟 focus → keydown → keypress → input → keyup → blur 这个完整的事件链，React 的状态更新能正常触发。

### Shadow DOM 穿透

有些网站用 Web Components，表单元素藏在 Shadow DOM 里，普通的 querySelector 找不到。AI Helper 的元素定位支持 Shadow DOM 穿透，能深入 shadow root 内部找到目标元素。

### 富文本编辑器

遇到 contenteditable 的富文本编辑器（比如 ProseMirror、Quill），`fill_form` 也能处理。它会先 focus 编辑器，然后通过 `document.execCommand('insertText', ...)` 或 dispatch input 事件来写入内容：

```javascript
// 简化示意：富文本编辑器写入逻辑
editor.focus();
document.execCommand('insertText', false, content);
// 触发 input 事件让框架感知变化
editor.dispatchEvent(new InputEvent('input', { bubbles: true }));
```

## 安全机制

自动操作网页这件事，安全性很重要。AI Helper 的设计是：

| 机制 | 说明 |
|------|------|
| 敏感操作确认 | 点击提交按钮、删除等操作需用户确认 |
| 超时自动拒绝 | 确认弹窗 30 秒无响应自动拒绝 |
| 操作日志 | 所有工具调用记录在侧边栏，可查看 |

不会出现你说了一句话，AI 就静默地把你账号删了的情况。涉及"提交""删除""支付"这类操作，一定会弹确认框等你点。

## 一个测试场景的完整流程

拿"测试注册功能"来说，完整流程是这样的：

1. 打开注册页面
2. 在侧边栏说："填入测试数据并提交"
3. AI 分析表单结构，识别出 5 个输入框 + 1 个下拉框 + 1 个提交按钮
4. 逐个调用 `fill_form` 填写文本字段
5. 调用 `select_dropdown` 选择下拉项
6. 弹出确认框："即将点击注册按钮，是否继续？"
7. 你点确认，AI 调用 `interact_element` 点击提交
8. 页面跳转，AI 可继续检查注册结果

如果要批量测试，配合 AI Helper 的多智能体功能，可以派多个 Agent 同时测试不同表单。

## 小结

自动填表单这个功能，测试同学用来做回归测试、运营同学用来批量录入，都能省不少时间。关键是不需要写自动化脚本，用自然语言描述需求就行。
