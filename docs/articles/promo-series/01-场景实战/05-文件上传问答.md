# 文件上传 AI 问答：PDF/Word/Excel 直接对话

你有没有遇到过这样的情况：手里有一份 50 页的 PDF 行业报告，想让 AI 帮你总结要点，但 ChatGPT 的文件上传有大小限制，或者你用的 AI 平台根本不支持文件上传。

又或者你有一个 Excel 销售数据表，想让 AI 分析一下趋势，但复制粘贴进去格式全丢了。

今天介绍的开源 Chrome 扩展 AI Helper，直接在浏览器侧边栏就能处理 PDF、Word、Excel 和 50 多种文本格式的文件，不需要上传到任何第三方平台。

## 支持的文件格式

AI Helper 的文件处理能力基于纯前端方案，不需要后端服务：

| 文件类型 | 处理方案 | 说明 |
|----------|----------|------|
| PDF | PDF.js | 全文文本提取，保留页面结构 |
| Word .docx | mammoth.js | 提取文本和基本格式 |
| Excel .xlsx/.xls | SheetJS | 多 sheet 支持，可导出 CSV |
| 纯文本 | 原生 API | 50+ 格式（.txt/.md/.json/.py/.js 等） |

关键点是：所有文件解析都在浏览器本地完成，文件内容不会上传到第三方服务器（除了发给 AI 模型做分析）。

## 两种工作模式

AI Helper 的文件处理有两种模式，取决于你是否连接了 Node.js 代理服务：

### 模式一：连接 Agent（推荐）

如果你启动了 AI Helper 的 Node.js 代理服务，文件会自动上传到代理服务的工作目录。AI 可以直接读取文件内容、执行脚本处理数据，能力更强。

比如处理 Excel 时，AI 可以写一段脚本来做数据清洗和分析：

```
请分析这个 Excel 文件里每个月的销售数据，
计算环比增长率，找出增长最快和最慢的月份
```

AI 会读取文件、编写分析脚本、执行脚本、返回结果。配合工作区管理功能，你还能在侧边栏直接浏览和管理本地文件系统。

### 模式二：未连接 Agent

没启动代理服务也没关系，AI Helper 会在浏览器端用 JavaScript 库提取文件内容，然后把文本发给 AI 模型。对于纯文本类的文件（PDF 文字、Word 文字、代码文件），效果一样好。

## 文件预览栏

上传文件后，侧边栏会出现一个文件预览区域，显示：

- 文件名和大小
- 提取状态（处理中 / 完成 / 失败）
- 文件内容预览

支持的预览格式包括文本、代码（带语法高亮）、PDF、Word、Excel 和图片。不用下载文件就能在侧边栏里直接看内容。

## 图片识别：多图对比分析

除了文档，AI Helper 还支持图片上传和识别。几个实用的设计：

**自动压缩**：上传的图片会自动压缩到 1024px 宽度 + JPEG 65% 质量，避免大图把 Token 预算撑爆。

**多图上传**：可以同时上传多张图片做对比分析。比如上传三张设计稿，让 AI 对比风格差异：

```
对比这三张 UI 设计稿，从布局、配色、信息层次三个维度分析优缺点
```

**独立 Vision API**：如果你不想用默认的 DeepSeek 模型处理图片，可以单独配置一个 Vision API 端点。图片识别请求走单独的接口，文字对话走主模型，各司其职。

## 图片标注编辑器

上传图片后，AI Helper 还提供了一个标注编辑器，支持 6 种标注工具：

| 工具 | 用途 |
|------|------|
| 画笔 | 自由绘制 |
| 矩形 | 框选区域 |
| 椭圆 | 圆形标注 |
| 箭头 | 指向特定位置 |
| 直线 | 画线 |
| 橡皮 | 擦除标注 |

支持撤销操作。标注完的图片可以保存下来，或者发给 AI 让它分析标注的内容。

这个功能在实际工作中挺好用的。比如你截了一张网页的图，用矩形框出有问题的区域，发给 AI 说"框出来的这个区域布局有问题，帮我分析原因"。

## 一个实际场景

假设你收到一份 PDF 格式的季度财务报告，想快速了解关键数据：

1. 在 AI Helper 侧边栏点击上传按钮，选择 PDF 文件
2. 文件预览栏显示文件信息，PDF.js 自动提取全文
3. 在对话框输入："这份报告的核心结论是什么？列出关键数据"
4. AI 阅读全文后输出摘要和关键数字

全程在浏览器侧边栏完成，不打开其他网站，不安装额外软件。

如果是 Excel 文件，连接了 Agent 的话，AI 甚至可以帮你生成数据图表。

## 小结

文件上传问答解决的核心问题是：**让 AI 直接处理你的本地文件，不用经过中间环节**。不管是 PDF 报告、Word 文档还是 Excel 数据，拖进侧边栏就能开始对话。
