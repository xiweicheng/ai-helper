- **目标**：慢慢积累口碑，不是一次性轰炸

## 写作规范

1. **准确**：基于项目最新代码状态，不编造功能
2. **克制**：讲清楚做了什么、为什么这么做，不吹"最强""唯一"
3. **有料**：每篇至少包含一个具体的技术细节或使用场景
4. **可读**：口语化表达，避免文档腔，适当用表格和代码块
5. **尾部**：每篇文末附项目地址，不硬推 Star
