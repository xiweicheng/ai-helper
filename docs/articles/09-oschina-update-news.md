# AI Helper 更新：浏览器 AI 助手新增定时任务、页面调试工具与侧边栏作用域模式

> 发布平台：开源中国「软件更新」资讯栏目
> 项目地址：GitHub / Gitee（见文末）

---

开源 Chrome 浏览器 AI 助手扩展 **AI Helper** 近日迎来一波密集更新，先后上线了**定时任务调度**、**基于 Chrome DevTools Protocol 的页面调试工具 `debug_page`**、**侧边栏作用域模式（全局 / 标签页绑定）**三大核心能力，并配套改进了聊天面板的历史定位与时间戳体验。

AI Helper 是一个采用 MIT 许可证开源的浏览器智能助手扩展，基于 ReAct（Reasoning + Acting）推理循环架构，内置 9 大类 50+ 工具，将大语言模型的推理能力与浏览器的操控能力深度结合，并可通过可选的 Node.js 本地代理服务突破浏览器沙箱，实现本地文件读写、命令执行、Skill 技能与 MCP 协议扩展。

以下是本次更新的主要内容。

## 一、定时任务：让 AI 按时开工

新版本加入了完整的定时任务调度能力，支持三种调度规则：

- **一次性任务**：多少分钟后执行，或指定时间点执行
- **间隔任务**：按固定周期重复执行
- **Cron 表达式**：满足更复杂的调度需求

任务可以基于指定网页上下文执行（抓取页面正文，或仅使用 URL），并挂载到宿主会话中。调度基于 Chrome Alarms 实现，Service Worker 重启后会自动重建任务，宿主会话被删除时也会自愈新建专属会话，保证任务不丢。

配套的管理面板支持任务的创建、编辑、删除、启用、停用与「立即执行」（自动定位宿主会话并滚动到底部等待结果），提供运行历史查询、后台失败系统通知，还可以通过「最多执行次数 / 截止时间」设置任务结束条件。

典型用法：每天早上 9 点自动抓取某个数据页面，让 AI 汇总成日报写入会话。

## 二、页面调试工具 debug_page：把 DevTools 的能力交给大模型

当常规内容脚本工具无法满足需求时，AI 现在可以调用基于 Chrome DevTools Protocol（`chrome.debugger`）的高级页面调试工具 `debug_page`。单个工具通过 `action` 参数提供 7 项能力：

| Action | 能力 |
|--------|------|
| `attach` / `detach` | 显式开启 / 关闭调试会话（attach 需用户在确认弹窗中放行） |
| `evaluate` | 在页面主世界执行任意 JS，支持 await Promise，自动捕获异常并截断超长返回 |
| `input` | 派发原生级鼠标 / 键盘事件（点击、输入、组合键、滚轮），可穿透 content script 无法触发的场景 |
| `network` | 两段式网络录制，记录请求 / 响应头、POST 数据、响应体，支持 URL 过滤与条数上限 |
| `screenshot` | 视口 / 整页 / 指定元素截图，支持 JPEG 质量参数，截图直接下载不占用模型上下文 |
| `emulate` | 模拟 User-Agent、视口设备指标、地理位置、时区、深色模式，支持一键 reset |

调试会话按标签页维护，支持附着复用，空闲 120 秒自动脱离以及时消除页面顶部的黄色调试提示条；对 `chrome://`、商店页等受限页面做了预检拦截；用户取消调试或 DevTools 抢占时会自动清理并给出可恢复的错误提示；活动会话期间通过 Alarms 维持 Service Worker 存活。

出于安全考虑，该工具**默认关闭**，需在工具面板手动启用；`attach` 操作走用户确认流程，普通 action 不打扰用户。

工程质量方面，本次更新抽出了零依赖的规则模块 `debugger-rules.js`（受限页面判定、按键规格解析、文本截断、网络条目序列化等），并新增 **104 个单元测试**（51 个纯规则用例 + 53 个执行器用例），全量 361 个单测通过。

## 三、侧边栏作用域模式：全局共享 or 标签页专属

选项页「基础」新增作用域单选开关，支持在两种模式间切换，配置写入后实时生效、无需重启扩展：

- **全局模式**（默认）：同一窗口内所有标签页共享同一份侧边栏实例，切换标签页时始终可见，符合 Chrome 侧边栏原生行为
- **标签页绑定模式**：侧边栏仅在打开它的标签页显示，可在多个标签页各自打开；切走自动隐藏、切回自动恢复

标签页绑定模式下还可开启**标签页自动分组**：把打开侧边栏的标签页统一归入一个彩色标签组便于识别，关闭侧边栏或切回全局模式时自动移出分组。

值得一提的是实现细节：由于 MV3 的 `sidePanel.setOptions` 无法可靠地"禁用"侧边栏，项目采用了「只启用不禁用 + 可选分组」的方案规避平台限制，并修复了构建产物 `manifest.json` 中 `side_panel.default_path` 覆盖运行时配置导致绑定作用域失效的问题。

## 四、聊天体验改进

- **用户问题列表面板**：聊天侧边栏新增「问题列表」，鼠标悬停消息跳转热区时右侧展开，便于快速定位历史提问
- **用户消息时间戳**：问题气泡下方常驻显示发问时间（今天显示时分，非今天显示日期，悬停查看完整时间），随消息持久化，刷新 / 重开面板仍显示原始发问时间；可在选项页开关，默认开启，切换后实时生效

AI Helper 无需付费订阅、无需注册账号，API 费用直接支付给所选模型厂商（兼容 OpenAI Chat Completions 协议，支持 DeepSeek / 通义千问 / GPT / Claude 等 30+ 模型）。

```bash

git clone https://gitee.com/xiweicheng/ai-helper.git
# 或 git clone https://github.com/xiweicheng/ai-helper.git

# Chrome 打开 chrome://extensions/ → 开发者模式 → 加载已解压的扩展程序 → 选择 dist 目录

# （可选）启动本地代理服务，解锁文件读写 / 命令执行 / Skill / MCP
npm install -g ai-helper-agent && aha start
```
