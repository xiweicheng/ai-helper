引言 ​

本文件面向 AI Helper 扩展（Manifest V3，侧边栏 side panel）中的图标系统，覆盖以下目标：

  • SVG 图标管理机制：集中常量、避免重复内联、按尺寸分组。
  • 动态加载与降级：文件类型图标、Emoji 降级、按需引入第三方库。
  • 缓存策略：工作目录、Agent 配置等探测结果缓存；图标本身以模块常量形式驻留内存。
  • 主题适配：基于 CSS Token 的亮/暗主题切换，图标颜色通过 currentColor 继承。
  • 性能优化：SVG 内联、构建期生成多尺寸 PNG、运行时按需加载 PDF/Word/Excel 解析器。
  • API 接口：图标获取方法、状态管理与错误处理。
  • 国际化与可访问性：i18n 文案、aria-hidden、语义化命名。
  • 设计规范：视觉一致性、语义化命名、版本管理。

项目结构 ​

图标相关代码分布在三个层次：

  • 设计层：icons/design-philosophy.md 描述“Neural Prism”视觉语言；icons/README.md 说明扩展应用图标尺寸要求。
  • 构建层：scripts/generate-icons.js 用 Sharp 从 SVG 模板渲染 16/48/128 三档 PNG，并输出对应 SVG 源文件。
  • 运行层：src/side_panel/icons.js 提供共享 SVG 常量；其他 UI 模块按需导入；文件类型图标由 file-extract.js 和 workspace-manager.js 提供 Emoji 降级方案。

详细组件分析 ​

共享 SVG 常量模块：src/side_panel/icons.js ​

该模块是图标系统的核心资产入口，职责包括：

  • 集中维护 16x16、24x24、1024x1024 三类 SVG 字符串常量。
  • 使用 fill="currentColor" 或 stroke="currentColor" 实现主题色继承。
  • 为不同场景提供专用 class，如 thinking-icon、tool-call-icon、dropdown-arrow。
  • 避免在多个 UI 文件中重复内联 SVG，降低体积与维护成本。

关键分类：

  • 16x16：复制、勾选、编辑等小尺寸操作图标。
  • 24x24：思考大脑、时钟、箭头、关闭、工具、图片、外部链接、下载、终端、文件、搜索等常用功能图标。
  • 1024x1024：引用、导出、Word/PDF 文档等大尺寸业务图标。

文件类型图标模块：file-extract.js 与 workspace-manager.js ​

两个模块都提供 getFileIcon，但用途略有差异：

  • file-extract.js：用于附件提取流程，按文件类别返回 Emoji，如 PDF、Word、Excel、文本、未知类型。
  • workspace-manager.js：用于工作区文件列表，支持目录与扩展名映射，默认回退到通用文档 Emoji。

图标构建脚本：scripts/generate-icons.js ​

该脚本负责生成扩展应用图标（非侧边栏 UI 图标），遵循 “Neural Prism” 设计哲学：

  • 使用 Sharp 将 SVG 模板渲染为 16/48/128 PNG。
  • 同时保存 SVG 源文件，便于后续调整。
  • 颜色采用固定调色板：深靛蓝、电光蓝、紫罗兰、青色火花。

依赖关系分析 ​

图标系统的依赖关系清晰且低耦合：

  • UI 模块仅依赖 icons.js 提供的常量，不直接操作 SVG 路径。
  • 文件类型图标模块独立于 UI 模块，提供 Emoji 降级。
  • 主题系统通过 CSS Token 影响所有 currentColor 图标，无需 JS 干预。
  • 构建脚本与运行时代码解耦，产物为 PNG/SVG 文件。

性能与优化 ​

  • SVG 内联优化：icons.js 将常用 SVG 定义为模块常量，避免重复内联，减少 DOM 重建开销。
  • 构建期生成：扩展应用图标通过 Sharp 在构建时生成 PNG，避免运行时缩放损耗。
  • 按需加载：PDF/Word/Excel 解析器在文件提取流程中动态 import，避免首屏加载无关库。
  • 降级策略：当 Agent 不可达或文件格式不支持时，回退到浏览器端提取或 Emoji 图标，保证 UI 可用。
  • 缓存策略：工作目录、家目录、Agent 配置等探测结果在模块内缓存，减少重复网络请求。

主题适配与可访问性 ​

  • 亮/暗主题切换：theme.js 管理用户偏好与生效主题，写入 <html data-theme>；theme.css 定义亮/暗两套 Token。
  • 颜色继承：图标 SVG 使用 fill="currentColor" 或 stroke="currentColor"，自动继承当前文本颜色，从而适配主题。
  • 可访问性：部分图标按钮使用 aria-hidden="true" 隐藏装饰性图标，确保屏幕阅读器聚焦语义元素。
  • 尺寸自适应：SVG 使用 viewBox 与相对单位，配合 CSS 控制宽高，实现不同容器下的自适应显示。

状态管理与错误处理 ​

  • 文件提取状态：processFile 设置 extracting、done、error 状态，并更新 UI。
  • Agent 连接错误：isAgentUnreachableError 判断网络失败，记录 debug 日志，避免控制台噪音。
  • 资源加载失败：动态 import 解析器失败时抛出错误，由上层捕获并降级。

使用示例 ​

  • 在 UI 组件中使用图标：导入 icons.js 常量，将 SVG 字符串赋值给 innerHTML。
  • 动态切换图标：根据状态切换不同常量，如思考中显示 ICON_BRAIN_24，完成后显示 ICON_CHECKMARK_16。
  • 处理加载失败：捕获 processFile 异常，设置 error 状态并提示用户。

故障排查 ​

  • 图标不显示：检查 icons.js 中对应常量是否存在，确认 DOM 插入逻辑正确。
  • 主题颜色异常：确认 theme.js 已初始化，data-theme 属性已设置，图标 SVG 使用 currentColor。
  • 文件图标为 Emoji：这是预期行为，如需自定义文件图标，需扩展 getFileIcon 映射。
  • Agent 不可达：检查网络连接与 Agent 服务状态，查看日志中的 agent unreachable 提示。

设计规范与版本管理 ​

  • 视觉一致性：遵循 “Neural Prism” 设计哲学，使用六边形晶体结构与固定调色板。
  • 语义化命名：图标常量命名包含尺寸与用途，如 ICON_IMAGE_24、ICON_COPY_16。
  • 版本管理：扩展应用图标由构建脚本生成，UI 图标常量集中在 icons.js，便于统一维护。
  • 国际化支持：图标按钮的标题与提示通过 i18n 文案动态设置，确保多语言环境下的可用性。
