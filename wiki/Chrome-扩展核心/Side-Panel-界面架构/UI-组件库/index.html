引言 ​

本文件面向“AI Helper”扩展的 UI 组件层，聚焦侧边栏界面中的 Markdown 渲染引擎、图片处理组件、图标系统、通用工具函数、样式与主题机制，以及可访问性与性能优化策略。文档以代码级实现为依据，给出架构图、流程图和关键调用链，帮助读者在不直接阅读源码的情况下理解并复用这些组件构建新的界面元素。

核心组件 ​

  • Markdown 渲染引擎：负责解析 Markdown、安全清洗、Mermaid 图表渲染、代码块复制、表格工具栏、导出为图片等。

  • 主题系统：基于 CSS 变量的亮/暗/跟随系统三态主题，支持无闪烁应用与跨页面同步。

详细组件分析 ​

Markdown 渲染引擎 ​

职责包括：

  • 提取并占位化 Mermaid 代码块、普通代码块、表格，再交由 marked 解析。
  • 使用 DOMPurify 进行安全清洗，禁止危险标签与事件属性。
  • 按需加载 mermaid 并渲染图表，提供缩放、拖拽、复制、下载 PNG、查看源代码等功能。
  • 为代码块添加复制按钮；为表格提供复制 Markdown、复制富文本、导出 Excel、导出图片等工具栏。
  • 将 Mermaid 图表转换为 PNG 时清理 foreignObject、移除外部资源引用，防止 Canvas 污染。

关键实现要点：

  • 主题切换重渲染：根据当前生效主题重新初始化 Mermaid，清空已渲染 SVG 后按原始代码再次渲染。
  • 导出白底语义：SVG→PNG、html2canvas 导出均强制使用白色背景，保证离线可读性。

图像处理组件 ​

职责包括：

  • 图片上传与压缩：根据原图尺寸动态计算目标宽高与质量，降低 Token 消耗。
  • 预览与多图导航：支持上一张/下一张、键盘左右切换、Esc 关闭。
  • 缩放与平移：滚轮缩放、鼠标拖拽平移、双击切换 1x/2x。
  • 标注编辑：画笔、橡皮擦、矩形、椭圆、箭头、直线，支持撤销与确认合成新图。
  • 附件状态同步：将压缩图与原图 URL、尺寸写入 state.attachedImages，供消息发送与历史展示使用。

性能与可访问性 ​

性能优化策略 ​

  • 懒加载第三方库：仅在首次需要时注入 Mermaid/jsPDF/html2canvas，避免首屏阻塞。
  • Mermaid 渲染容错：逐个容器渲染，单个失败不影响其他图表；失败时恢复原始内容。
  • 事件委托：代码复制与表格工具栏按钮在 document 捕获阶段一次性绑定，避免大量逐钮监听。
  • Canvas 优化：图片编辑使用两个 Canvas 分层，预览层仅临时绘制，确认后合成到原图尺寸。
  • 导出白底：SVG→PNG、html2canvas 导出固定白底，避免主题色影响离线可读性。

  • 所有颜色通过 CSS 变量 Token 管理，支持亮/暗/跟随系统三态。
  • 主题值由 theme.js 写入 <html data-theme>，CSS 通过 [data-theme="dark"] 覆盖暗色值。
  • 导出物（PNG/PDF/复制富文本）保持白底黑字，不受暗黑主题影响。

故障排查指南 ​

  • Mermaid 渲染失败：
    • 检查是否已加载 Mermaid 库；若加载失败会记录警告并跳过渲染。
    • 单个容器失败不影响其他图表；失败时会恢复原始内容并显示错误提示。
  • 图片导出失败：
    • 检查 html2canvas 是否加载成功；失败时 Toast 提示“图片导出库未加载”。
    • Canvas toDataURL 失败时尝试 JPEG 降级；仍失败则抛出错误。
  • 主题切换异常：
    • 检查 theme.js 是否正确设置 data-theme；确认 CSS 中对应覆盖规则存在。
    • 导出功能应保持白底，不应受主题影响。
