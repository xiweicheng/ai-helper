引言 ​

本文件面向"AI Helper"扩展的 UI 组件层，聚焦侧边栏界面中的 Markdown 渲染引擎、图片处理组件、图标系统、通用工具函数、样式与主题机制，以及可访问性与性能优化策略。文档以代码级实现为依据，给出架构图、流程图和关键调用链，帮助读者在不直接阅读源码的情况下理解并复用这些组件构建新的界面元素。

更新 本次更新新增了全屏覆盖系统、头部工具栏导出功能、增强的复制功能和响应式设计优化，为开发者提供了更完整的 UI 组件生态。

核心组件 ​

  • 全屏覆盖系统：负责消息节点的动态迁移、流式跟随滚动、键盘导航和退出全屏逻辑。
  • 头部工具栏导出：提供 Word、PDF、图片、Markdown 四种格式的导出功能，支持异步处理和错误恢复。
  • 增强复制功能：支持纯文本和富文本复制，包含 ClipboardItem API 使用和多种降级方案。
  • Markdown 渲染引擎：负责解析 Markdown、安全清洗、Mermaid 图表渲染、代码块复制、表格工具栏等。
  • 图像处理组件：负责图片上传、压缩、预览、多图导航、缩放平移、标注编辑等。
  • 图标系统：集中管理 SVG 图标常量，统一使用 fill="currentColor" 配合主题色。
  • 通用工具函数：日期格式化、Token 计数、文件大小格式化、字符串转义等。
  • 第三方库懒加载：按需加载 Mermaid、jsPDF、html2canvas，避免首屏体积过大。
  • 主题系统：基于 CSS 变量的亮/暗/跟随系统三态主题，支持无闪烁应用与跨页面同步。
  • Offscreen Document 剪贴板兼容层：解决 MV3 扩展权限限制，提供剪贴板读写兼容方案。

详细组件分析 ​

全屏覆盖系统 ​

职责包括：

  • 消息节点迁移：将当前消息 DOM 节点从聊天容器移动到全屏覆盖层，原位留注释锚点。
  • 流式跟随滚动：在流式输出中自动滚动到底部，用户上滚时暂停跟随。
  • 键盘导航：支持 Alt+F 快捷键、Esc 退出全屏、Alt+双击进入全屏。
  • 头部工具栏：集成复制按钮和导出下拉菜单。
  • 状态管理：维护全屏状态、滚动位置、锚点信息等。

Markdown 渲染引擎 ​

职责包括：

  • 提取并占位化 Mermaid 代码块、普通代码块、表格，再交由 marked 解析。
  • 使用 DOMPurify 进行安全清洗，禁止危险标签与事件属性。
  • 按需加载 mermaid 并渲染图表，提供缩放、拖拽、复制、下载 PNG、查看源代码等功能。
  • 为代码块添加复制按钮；为表格提供复制 Markdown、复制富文本、导出 Excel、导出图片等工具栏。
  • 将 Mermaid 图表转换为 PNG 时清理 foreignObject、移除外部资源引用，防止 Canvas 污染。

图像处理组件 ​

职责包括：

  • 图片上传与压缩：根据原图尺寸动态计算目标宽高与质量，降低 Token 消耗。
  • 预览与多图导航：支持上一张/下一张、键盘左右切换、Esc 关闭。
  • 缩放与平移：滚轮缩放、鼠标拖拽平移、双击切换 1x/2x。
  • 标注编辑：画笔、橡皮擦、矩形、椭圆、箭头、直线，支持撤销与确认合成新图。
  • 附件状态同步：将压缩图与原图 URL、尺寸写入 state.attachedImages，供消息发送与历史展示使用。

性能与可访问性 ​

性能优化策略 ​

  • 懒加载第三方库：仅在首次需要时注入 Mermaid/jsPDF/html2canvas，避免首屏阻塞。
  • 全屏节点迁移：使用 DOM 节点迁移而非克隆，保留事件监听器，减少内存占用。
  • 流式跟随优化：使用 ResizeObserver 和 passive 事件监听器，避免频繁重排。
  • 异步导出处理：导出功能使用动态导入，避免阻塞主线程。
  • Mermaid 渲染容错：逐个容器渲染，单个失败不影响其他图表；失败时恢复原始内容。
  • 事件委托：代码复制与表格工具栏按钮在 document 捕获阶段一次性绑定，避免大量逐钮监听。
  • Canvas 优化：图片编辑使用两个 Canvas 分层，预览层仅临时绘制，确认后合成到原图尺寸。
  • 导出白底：SVG→PNG、html2canvas 导出固定白底，避免主题色影响离线可读性。

样式隔离与主题适配 ​

主题 Token 体系 ​

  • 所有颜色通过 CSS 变量 Token 管理，支持亮/暗/跟随系统三态。
  • 主题值由 theme.js 写入 <html data-theme>，CSS 通过 [data-theme="dark"] 覆盖暗色值。
  • 导出物（PNG/PDF/复制富文本）保持白底黑字，不受暗黑主题影响。

  • 全屏模式异常：
    • 检查消息节点是否正确迁移到覆盖层。

    • 检查对应库是否加载成功（docx、pdf-lib、html2canvas）。
    • 验证内容预处理是否正确（Mermaid 渲染、SVG 转换）。
    • 确认文件格式生成和下载流程。
  • 复制功能异常：
    • 检查 ClipboardItem API 是否可用。
    • 验证 Offscreen Document 权限和通信。
    • 确认降级方案是否正常工作。
  • 主题切换异常：
    • 检查 theme.js 是否正确设置 data-theme。
    • 确认 CSS 中对应覆盖规则存在。
    • 验证导出功能应保持白底，不应受主题影响。
