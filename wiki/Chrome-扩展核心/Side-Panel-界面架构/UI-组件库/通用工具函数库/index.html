引言 ​

本文件聚焦“通用工具函数库”的体系化说明，覆盖日期时间处理、字符串处理、DOM 操作封装、数据结构工具、错误处理机制、性能优化策略以及测试覆盖情况。该工具能力并非单一模块，而是分布在共享层、侧边栏、内容脚本与 Agent 测试辅助中，分别承担不同运行环境的通用职责：

  • 共享层提供跨环境的基础工具（节流/防抖、基础格式化、HTML 转义、深拷贝、扩展通信）。
  • 侧边栏工具侧重 UI 展示与交互（时长/Token/聊天时间格式化、属性转义、剪贴板、弹窗定位等）。
  • 内容脚本工具专注页面 DOM 操作（唯一选择器生成、文本高亮、自动等待、富文本填充等）。
  • Agent 测试辅助提供示例级时间格式化与本地化输出，用于验证 MCP 工具行为。

核心组件 ​

本节按能力域归纳工具函数，并给出使用要点与注意事项。

日期时间处理 ​

  • 基础格式化

    • 共享层提供 formatDate，基于浏览器本地化输出中文时间。
    • 侧边栏提供 formatDuration（时长）、formatChatTime（聊天短格式）、formatChatTimeFull（完整格式），均结合语言设置进行本地化。
    • 工作区管理器提供 formatFileSize 与 formatTime，用于文件列表展示。
    • 选项页提供 CPU 时间与运行时长格式化，面向进程监控场景。
    • Agent 测试辅助提供 get_time 工具示例，演示 ISO/Unix/本地化三种输出。

  • 时区与本地化

    • 侧边栏时间格式化通过 getLanguage() 切换中英文显示；共享层 formatDate 固定中文区域。
    • Agent 测试示例显式指定 Asia/Shanghai 时区，体现本地化输出可配置性。

  • 最佳实践

    • 对外展示统一走侧边栏格式化函数，避免散落的 toLocaleString 调用。
    • 对需要稳定解析的时间戳，先校验 isNaN(Date.parse(...)) 再格式化。
    • 对长对话时间，优先使用 formatChatTime，仅在 hover 或详情中使用 formatChatTimeFull。

字符串处理 ​

  • 文本截断

    • 共享层提供 truncateText，简单长度截断并追加省略号。
    • 审计日志调试用例中存在更复杂的截断语义（带被截字符数提示），体现业务侧对截断信息的增强需求。

  • HTML 转义与属性转义

    • 共享层与侧边栏均实现 escapeHtml，通过创建临时 div 安全转义。
    • 侧边栏额外提供 escapeAttr，对属性值做更严格的特殊字符替换。

  • 正则表达式封装

    • 内容脚本提供 highlightTextMatches，基于 TreeWalker 仅包裹命中文本节点，避免破坏框架虚拟 DOM 与事件绑定。
    • Markdown 渲染与导出逻辑中包含行内 Markdown 解析的正则链，注意先转义再解析，防止 XSS。

  • 编码解码

    • 共享层未直接提供编解码工具；Agent 端存在轻量加密/解密工具（不在本仓库前端工具集范围内），侧边栏在查询余额时通过共享密钥解密 API Key。

  • 最佳实践

    • 所有用户输入进入 DOM 前必须经过 escapeHtml 或 escapeAttr。
    • 正则匹配需限制最大结果数，避免整页大量包裹导致重排。
    • 对富文本编辑器，优先使用原生 setter 或 insertText，再触发 input/change 事件。

DOM 操作封装 ​

  • 元素查询与选择器

    • 内容脚本提供 generateUniqueSelector 与 getElementSelector，根据 id、class、层级生成稳定选择器。
    • 提供 getElementText 与 getElementValue，适配 INPUT/SELECT 等表单元素。

  • 事件绑定与交互

    • 内容脚本提供 autoWaitAfterAction，检测 URL 与 DOM 签名变化，自动等待页面稳定。
    • 侧边栏提供 Toast、输入框高度自适应、下拉弹出框定位、复制剪贴板等交互工具。

  • 样式操作与属性管理

    • 内容脚本提供 highlightTextMatches 与 removeHighlights，安全注入/清理高亮样式。
    • 侧边栏弹窗具备点击外部关闭、锚点状态标记、边界约束等属性管理逻辑。

  • 最佳实践

    • 高亮只包裹文本节点，不触碰元素标签与属性，确保框架可感知。
    • 自动等待采用最小等待 + 连续稳定计数，避免无谓阻塞。
    • 弹窗定位需考虑视口边界与锚点位置，避免溢出屏幕。

数据结构工具 ​

  • 深拷贝

    • 共享层提供 deepClone，基于 JSON 序列化/反序列化实现浅兼容深拷贝。
    • 注意：不支持循环引用、函数、Symbol、undefined、Date、RegExp 等特殊对象。

  • 对象合并

    • 国际化模块内部实现 deepMerge，用于合并多语言翻译字典，支持嵌套对象合并与数组不合并。

  • 类型检查与数据验证

    • 共享层未提供通用类型检查工具；Agent 侧 RAG 与记忆服务包含入参校验（如集合 ID 正则、topK 上限、导入体积上限、记忆类型白名单等），可作为后端数据校验参考。

  • 最佳实践

    • 对复杂对象深拷贝，建议引入专用库或自定义结构化克隆方案。
    • 对外部输入一律校验类型与范围，失败快速返回，避免污染下游。

错误处理机制 ​

  • 异常捕获

    • 内容脚本高亮包裹使用 try/catch 跳过失效节点，保证批量操作鲁棒性。
    • 侧边栏 DeepSeek 余额查询失败时隐藏余额区块，避免 UI 闪烁。
    • 共享层扩展消息发送封装 Promise，遇到 lastError 返回 null，调用方需判空。

  • 日志记录

    • 侧边栏复制失败通过 logger.error 输出错误；Agent 服务端启动时开启控制台日志输出。

  • 调试信息输出

    • 调试执行器将 CDP 异常描述、返回值过长截断等信息以可读方式返回给调用方。

  • 最佳实践

    • 所有异步网络/存储调用均需 catch 分支，降级或提示用户。
    • 对用户可见的错误信息应本地化，避免暴露原始堆栈。

性能优化策略 ​

  • 函数节流与防抖

    • 共享层提供 throttle 与 debounce，适用于滚动、输入、窗口 resize 等高频事件。
    • 审计写入、统计落盘等场景应避免同步写 storage，改为内存聚合 + 定时落盘。

  • 内存优化

    • 避免在循环内重复计算 Token 估算或全量序列化工具定义。
    • 避免将大段 HTML/日志存入 element.dataset，改用内存 Map 缓存。
    • 监听器需成对移除，防止泄漏（如预览面板鼠标/滚轮监听）。

  • 最佳实践

    • 高频事件统一走节流/防抖包装。
    • 大对象缓存与 DOM 属性分离，减少重排重绘。
    • 定时器与轮询需有上限与清理逻辑。

详细组件分析 ​

共享工具模块（shared/utils.js） ​

  • 功能要点

    • 节流/防抖：封装高频事件回调，避免重复执行。
    • 基础格式化：formatDate 输出本地化时间。
    • 字符串工具：truncateText、escapeHtml。
    • 数据结构：deepClone。
    • 扩展通信：getExtensionId、getCurrentTabId、sendMessageToTab、sendMessageToBackground。

  • 复杂度与边界

    • deepClone 为 O(n) 序列化开销，不适用于含函数/Symbol/循环引用的对象。
    • 扩展通信封装 Promise，lastError 时返回 null，调用方需判空。

  • 优化建议

    • 对频繁调用的通信封装，可在上层加缓存或去重。
    • 对大对象深拷贝，建议按需字段拷贝或引入结构化克隆。

侧边栏工具模块（side_panel/utils.js） ​

  • 功能要点

    • UI 格式化：formatDuration、formatChatTime、formatChatTimeFull、formatTokenCount、formatTokenFull。
    • 转义：escapeHtml、escapeAttr。
    • 交互：Toast、输入框高度自适应、下拉定位、复制剪贴板、Token 弹窗。
    • 系统提示词拼接：动态注入命令环境、代理主机、术语定义、任务拆解、长期记忆规则等。

  • 本地化与时间

    • 时间格式依据当前语言（中文/英文）输出不同样式。
    • 弹窗文案通过 t() 获取，支持参数插值。

  • 最佳实践

    • 所有用户可见文案必须走 t()，禁止硬编码。
    • 弹窗定位需考虑视口边界与锚点位置，避免溢出。
    • 网络请求失败需隐藏相关区块，避免 UI 残留。

  • 安全与稳定性

    • 高亮仅包裹文本节点，不修改元素结构与属性，避免破坏框架虚拟 DOM。
    • 自动等待基于 URL 与 DOM 签名变化，兼顾导航与局部刷新。

  • 最佳实践

    • 高亮前清空旧高亮，避免累积。
    • 富文本输入后派发 input/change 事件，确保受控组件感知。

性能考虑 ​

  • 节流与防抖

    • 高频事件（滚动、输入、resize）统一使用 throttle/debounce。
    • 避免在事件回调中进行昂贵计算或 DOM 全量扫描。

  • 存储与 IO

    • 审计日志与统计写入应改为内存聚合 + 定时落盘，避免每次操作都读写 storage。
    • 大对象缓存与 DOM 属性分离，减少重排重绘。

  • 监听器与定时器

    • 监听器需成对移除，防止泄漏。
    • 定时器与轮询需有上限与清理逻辑，避免常驻内存占用。

  • 代码法优化

    • 循环内避免重复估算 Token 或序列化工具定义。
    • 使用增量扣减与缓存值，降低 CPU 消耗。

故障排查指南 ​

  • 常见问题

    • 时间格式为空：检查输入是否为合法 ISO 字符串，先校验 isNaN。
    • 高亮不生效：确认根节点有效、正则已加 g 标志、命中区间非空。
    • 弹窗溢出屏幕：检查定位逻辑是否考虑视口边界与锚点位置。
    • 复制失败：检查 clipboard API 权限，回退到 execCommand 方案。
    • 扩展消息失败：检查 lastError，调用方需判空。

  • 调试建议

    • 使用调试执行器查看 CDP 异常描述与返回值截断信息。
    • 对网络请求失败，记录 HTTP 状态码与响应体摘要。
    • 对存储写入失败，保留脏标并在下一次落盘时重试。

结论 ​

本工具函数库以共享层为核心，向上支撑侧边栏 UI 与内容脚本 DOM 操作，向下通过扩展通信与 Agent 端能力协同。其设计强调：

  • 本地化与安全性：所有文案走 i18n，所有用户输入经转义。
  • 性能与鲁棒性：节流/防抖、自动等待、高亮安全包裹、监听器清理。
  • 可扩展性：模块化注册翻译、工具函数职责清晰、契约测试对齐前后端。

建议在后续迭代中继续推进：

  • 引入结构化克隆替代 JSON 深拷贝。
  • 统一时间格式化入口，收敛区域设置。
  • 完善单元测试覆盖，尤其针对边界条件与异常路径。
