引言 ​

本文件面向“MCP（Model Context Protocol）协议扩展”的完整技术文档，覆盖以下目标：

  • 详细说明 MCP 客户端实现：连接管理、传输层选择、消息传递、工具自动发现与远程工具调用。
  • 说明 MCP 注册表工作原理：多服务器管理、工具扁平化聚合、动态连接/断开、错误处理与日志。
  • 解释 MCP 配置系统：配置文件位置与格式、读写并发控制、启用状态切换、语言国际化注入。
  • 描述 Skill 技能系统架构：Workflow 与 Agent 两类技能、Markdown 定义、模板引擎、执行框架与生命周期。
  • 提供 MCP 协议规范参考：消息语义、工具定义语法、事件类型与错误码。
  • 给出实际 MCP 服务器集成示例与技能开发指南，涵盖认证、日志记录与性能监控。

本项目为双进程架构：Chrome 扩展端（Manifest V3）+ 独立本地代理端 Agent（Node.js）。两端版本号保持同步，当前以 2.3.1 为准；Agent 源码修改后必须重启进程，新接口才生效。

核心组件 ​

  • MCP 客户端（McpClient）：封装 Model Context Protocol SDK 客户端，支持 stdio、SSE、Streamable HTTP、WebSocket 四种传输；负责建立连接、拉取工具列表、调用工具并返回统一结果。
  • MCP 配置（mcp-config.js）：管理 ~/.ai-helper-agent/mcp_servers.json，提供缓存、写锁、增删改查与启用状态切换。
  • MCP 注册表（registry.js）：维护已连接客户端 Map，启动时连接所有启用的 MCP Server，暴露工具扁平化查询与工具调用转发。
  • Skill 加载器（loader.js + markdown-loader.js）：扫描 skills 目录，加载 Workflow JSON/YAML 与 Agent SKILL.md，支持 ZIP/URL 导入与安全校验。
  • Skill 执行器（executor.js）：解析步骤 DAG、拓扑排序并行执行、条件跳过、参数模板渲染、超时与部分成功处理。
  • Skill 注册表（registry.js）：内存注册、模糊查找、启用/停用持久化、内置技能保护、Agent Prompt 注入。
  • 模板引擎（template.js）：支持 {{var}} 替换与 {{#if}} 条件渲染。
  • 安全与配置（security.js、config.js）：路径白名单、硬阻止、命令分级、配置加密落盘、配对与认证。
  • 审计日志（logger.js）：JSON Lines 日志、按日轮转、清理策略、分类标签。

详细组件分析 ​

MCP 客户端与连接管理 ​

  • 传输层选择：根据 serverConfig.transport 创建 Stdio/SSE/Streamable HTTP/WebSocket 传输实例；缺失必要字段时抛出翻译后的错误。
  • 连接流程：构造 Client，connect 成功后获取 serverInfo、capabilities，并调用 listTools 拉取工具列表；失败则 disconnect 并返回错误信息。
  • 工具调用：封装 callTool，将 result.error 与 content.text 聚合为统一返回体；未连接直接返回“未连接”错误。
  • 生命周期：disconnect 关闭 client 与 transport；getStatus 返回连接状态与工具数量。

MCP 配置系统 ​

  • 配置文件：~/.ai-helper-agent/mcp_servers.json，包含 servers 数组。
  • 缓存与写锁：loadMcpConfig 使用 mtime 缓存；saveMcpConfig 通过 withWriteLock 串行写入，避免并发覆盖。
  • 操作接口：addMcpServer、removeMcpServer、toggleMcpServer 均先 load 再 save，保证一致性。
  • 默认行为：不存在文件时创建空 servers 数组。

MCP 注册表与工作流 ​

  • 初始化：initializeMcpRegistry 遍历 config.servers，仅连接 enabled=true 的服务器，统计 connected/failed 并输出日志。
  • 工具发现：getMcpTools 将所有已连接服务器的 tools 扁平化为统一结构，支持按 serverId 过滤。
  • 工具调用：callMcpTool 校验 serverId 与连接状态，转发至对应 McpClient.callTool。
  • 连接管理：connectMcpServer/disconnectMcpServer 支持重连与清理；shutdownMcpRegistry 在 Agent 关闭时释放资源。

Skill 技能系统架构 ​

  • 加载器（loader.js + markdown-loader.js）：
    • Workflow Skill：扫描 .json/.yaml/.yml，校验 name/description/steps，默认 enabled=true。
    • Agent Skill：扫描子目录中的 SKILL.md，解析 frontmatter 与正文，收集 resources（scripts/templates/assets/references），支持 ZIP/URL 导入与安全校验（DNS 解析、私有 IP 判断、ZIP 解压安全）。
  • 执行器（executor.js）：
    • 构建步骤 DAG，拓扑排序并行执行；支持 when 条件、dependsOn 依赖、变量上下文 step.id.*。
    • 内部工具映射：agent_file、agent_exec、agent_search 等，结合 security.checkPath/checkCommand 进行安全校验。
    • 超时控制（EXECUTION_TIMEOUT）、活跃执行上限（MAX_ACTIVE_EXECUTIONS）、部分成功（partial）与错误处理。
  • 注册表（registry.js）：
    • 初始化时种子写入 skill-creator，合并文件系统与内置技能，恢复启用状态（builtin_skills_state.json、disabled_skills.json）。
    • 提供 getSkillList/getSkill/runSkill/getAgentSkillPrompts/getAgentSkillPrompt/importSkill/removeSkill/toggleSkill/reloadSkills。
  • 模板引擎（template.js）：
    • renderTemplate/renderConditional/render 支持 {{var}} 与 {{#if var}}...{{/if}}，点号路径解析 a.b.c。

安全与权限控制 ​

  • 路径沙箱：checkPath 支持 ~ 展开、工作目录放行、allowedPaths 前缀匹配、realpath 防符号链接绕过、硬阻止敏感文件/目录。
  • 命令分级：checkCommand 对黑名单绝对禁止、灰名单需确认；支持链式命令拆分、包装器剥壳、内联载荷提取、命令替换特征检测。
  • 配置安全：memoryEmbedding.apiKey 落盘前编码，读取时解码；pairings.token 同样编码落盘。
  • 认证：verifyToken 基于 pairings.json；handlePairRequest 支持失败锁定、一次性配对码轮换。

依赖关系分析 ​

  • 低耦合高内聚：MCP 客户端仅依赖 SDK 传输层；注册表依赖配置与客户端；Skill 执行器依赖安全与搜索模块；注册表依赖加载器与执行器。
  • 外部依赖：@modelcontextprotocol/sdk（MCP 通信）、archiver（ZIP 打包）、ws（WebSocket）、fs/path/os/crypto 等 Node 标准库。
  • 潜在循环依赖：server.js 作为入口集中引入各模块，但模块间通过函数导出解耦，未见直接循环 import。

    • 超时保护：EXECUTION_TIMEOUT=300s，防止长时间阻塞。

    • JSON Lines 追加写入，按日轮转，保留最近 MAX_LOG_FILES=30 个文件，单文件超过 MAX_LOG_SIZE=10MB 清理。

故障排查指南 ​

  • MCP 连接失败：
    • 检查 serverConfig.transport 与必填字段（url/command/env/cwd）。
    • 查看 initializeMcpRegistry 日志中 failedServers 列表与错误信息。
  • 工具调用失败：
    • 确认 serverId 与 toolName 正确；检查 McpClient.callTool 返回的 error 与 raw。
  • Skill 执行异常：
    • 检查 parameters 必填项与类型转换；查看步骤回调 onStepUpdate 的状态与消息。
    • 注意 when 条件与 dependsOn 依赖是否形成死循环或缺失前置步骤。
  • 安全拦截：
    • checkPath 返回 forbiddenAgentFile/pathNotInAllowedDir/pathOutOfRange 时，调整 allowedPaths 或 workdir。
    • checkCommand 返回 deny/confirm 时，确认命令是否符合黑名单/灰名单规则。
  • 配置保存失败：
    • 检查 withWriteLock 是否被其他写入阻塞；确认文件权限与磁盘空间。
  • 认证问题：
    • verifyToken 失败时检查 pairings.json 与 token 是否过期或被轮换。
