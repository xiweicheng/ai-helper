引言 ​

本文件面向“交互操作工具”这一扩展端内容脚本能力，聚焦以下目标：

  • 元素定位与点击：支持 CSS 选择器、Shadow DOM 穿透、ref 引用、文本匹配；提供可见性检测、自动等待页面稳定。
  • 表单填写与提交：输入框填充、富文本编辑器兼容、下拉菜单选择、单选/复选框操作、文件上传模拟、自动触发 change/input 事件。
  • 滚动与导航控制：平滑滚动、视口定位、按文本滚动、无限滚动内容收集、滚动边界判定。
  • 键盘输入模拟：按键事件触发、组合键修饰符、输入法与富文本兼容性、无障碍名称解析。
  • 复杂用户交互示例：自动化登录流程、数据录入任务、页面导航与叠加层操作。
  • 错误处理策略、超时控制与性能优化建议。

该能力位于 Chrome 扩展的内容脚本层，通过 src/content 下的模块实现，供上层工具编排调用。

项目结构 ​

交互操作相关代码集中在内容脚本目录中，采用“功能域 + 共享工具”的组织方式：

  • interaction-tools.js：对外暴露的原子交互工具（点击、表单、滚动、等待、键盘、文件上传、下拉选择、存储管理）。
  • page-interaction.js：元素查询、ref 引用、可交互元素快照、按 ref 操作、滚动到文本等。
  • page-utils.js：通用工具（唯一选择器生成、DOM 签名、auto-wait、原生值设置、富文本填充）。
  • shadow-dom-utils.js：Shadow DOM 穿透查询。
  • demo-product-form.e2e.spec.js：端到端用例，演示多步骤表单、模态框、叠加层与 ref 操作。

核心组件 ​

本节从“能力维度”梳理工具集，并给出关键函数入口与行为要点。

  • 元素定位与点击

    • clickElement(selector, waitTime, timeout)：CSS 选择器点击，自动等待 URL/DOM 变化稳定。
    • clickByText(text, options)：按文本查找可交互元素并点击或悬停，返回匹配诊断信息。
    • interactByRef(ref, action, options)：基于 query_elements 返回的 ref 编号执行 click/hover/type。
    • getElementCount(selector, includeHidden)：快速统计元素数量（含可见计数）。

  • 表单填写与提交

    • fillForm(fields, waitTime)：批量填充 text/select/checkbox/radio/contenteditable，统一派发 input/change 事件。
    • selectDropdown(triggerSelector, optionText, optionSelector, timeout)：原生 select 与自定义下拉选择。
    • typeIntoElement(el, value, options)：内部原子输入（聚焦、清空、写入、可选 Enter 提交）。

  • 滚动与导航

    • scrollToPosition(options)：top/bottom/coordinates/selector 滚动，支持 smooth 行为与边界判定。
    • scrollToText(text, options)：滚动直到找到包含指定文本的元素并定位到视口中心。
    • scrollAndCollect(args)：无限滚动内容收集，去重后返回可视文本。

  • 可见性与等待

    • waitForElement(selector, state, timeout)：等待 appeared/disappeared/visible/hidden 状态。
    • isElementTrulyVisible(el)：严格可见性判断（display/visibility/opacity/尺寸/视口）。
    • autoWaitAfterAction(sigBefore, minWait, maxWait)：操作后自动等待页面稳定。

  • 键盘输入模拟

    • keyboardInput({ key, text, ctrlKey, shiftKey, altKey })：模拟按键与文本输入，兼容富文本与 React 受控组件。

  • 文件上传

    • fileUpload(selector, fileName, fileContent, fileType)：构造 File/Blob/DataTransfer 并触发 change。

  • 存储管理

    • manageStorage({ action, storage, key, value })：localStorage/sessionStorage 的 get/set/remove/clear。

详细组件分析 ​

元素定位与点击 ​

  • 选择器支持
    • 使用 deepQuerySelector 穿透 Shadow DOM，避免现代 Web Components 导致的定位失败。
    • 支持 CSS 选择器；XPath 未直接暴露，但可通过 CSS 表达常见定位需求。
  • 可见性检测
    • isElementTrulyVisible 综合 display/visibility/opacity/尺寸/视口判定，避免点到隐藏元素。
  • 点击与自动等待
    • clickElement 记录点击前 DOM 签名，点击后调用 autoWaitAfterAction 等待 URL/DOM 稳定。
    • clickByText 遍历可交互元素集合，精确/包含匹配文本，返回诊断信息（是否存在、是否隐藏、是否可点击）。
  • Ref 引用
    • queryInteractiveElements 输出树形快照并为每个元素分配稳定 ref；interactByRef 通过 WeakMap 跨快照复用编号，失效时回退 selector 重查。

表单填写与提交机制 ​

  • 输入框填充
    • 标准 input/textarea：通过 setNativeValue 绕过 React 受控组件监听，再派发 input/change 事件。
    • 富文本编辑器：fillContentEditable 优先 execCommand('insertText')，否则回退 textContent，并派发 input/change。
  • 下拉菜单选择
    • 原生 <select>：匹配 option.value 或 option.text，设置 value 并派发 change/input。
    • 自定义下拉：点击触发器，轮询选项容器匹配文本，点击匹配项。
  • 复选框/单选按钮
    • checkbox：设置 checked 并派发 change。
    • radio：支持 selector[value=x] 或同 name/value 组内查找，设置 checked 并派发 change。
  • 文件上传
    • 构造 Blob/File，通过 DataTransfer 赋值 input.files，派发 change。
  • 自动提交
    • typeIntoElement 支持 submit=true 时派发 Enter 键序列（keydown/keypress/keyup），触发表单提交。

滚动与导航控制 ​

  • 平滑滚动与视口定位
    • scrollToPosition 支持 top/bottom/coordinates/selector，behavior=smooth，block=center/left/right/top/bottom。
    • 边界判定：已在顶部/底部/坐标位置时标记 moved=false，便于循环检测器识别无进展。
  • 按文本滚动
    • scrollToText 先检查当前视口，若未命中则循环 scrollBy 并 pause，最终 scrollIntoView 居中。
  • 无限滚动内容收集
    • scrollAndCollect 按固定像素滚动，收集可视文本节点，去重相邻重复行，最后滚回起始位置。

键盘输入模拟 ​

  • 按键映射
    • KEY_CODE_MAP 提供常用键映射（Enter/Escape/Tab/Backspace/Delete/方向键/Home/End/PageUp/PageDown/Space/F1-F12）。
    • 字母/数字动态计算 code/keyCode，F键按规则计算 keyCode。
  • 文本输入
    • 对 contenteditable：execCommand('selectAll'/'insertText') 或 fallback textContent。
    • 对 input/textarea：setNativeValue + InputEvent(inputType='insertText') + change。
  • 组合键
    • 支持 ctrlKey/shiftKey/altKey 修饰符，派发 keydown/keypress/keyup 三件套。
  • 自动等待
    • 输入后调用 autoWaitAfterAction，检测导航或 DOM 变化并返回变化提示。

可见性检测与异步等待 ​

  • 严格可见性
    • isElementTrulyVisible 检查 offsetParent/display/visibility/opacity/尺寸/视口，确保元素真正可见。
  • 状态等待
    • waitForElement 轮询 appeared/disappeared/visible/hidden，超时返回结构化错误。
  • 操作后自动等待
    • autoWaitAfterAction 先等待最小时间，期间检测 DOM 签名变化，连续两次无变化视为稳定。

复杂用户交互场景示例 ​

  • 自动化登录流程
    • 步骤：定位用户名/密码输入框 → fillForm 填充 → 点击登录按钮 → waitForElement 等待登录成功标志 → 跳转检测。
    • 关键点：使用 autoWaitAfterAction 捕获导航变化；使用 isElementTrulyVisible 验证登录成功元素可见。
  • 数据录入任务
    • 步骤：fillForm 批量填充 → selectDropdown 选择分类 → fileUpload 上传附件 → interactByRef 提交。
    • 关键点：表单字段类型区分（text/select/checkbox/radio/contenteditable）；文件上传需校验 input.type==='file'。
  • 页面导航与叠加层操作
    • 步骤：queryInteractiveElements 获取快照 → 打开模态框 → 在叠加层内定位确认按钮 → interactByRef 勾选条款 → 点击确认。
    • 关键点：叠加层根判定（dialog/popover/menu/listbox）；ref 跨快照复用与失效回退。

性能与稳定性 ​

  • 性能优化建议
    • 优先使用 ref 引用而非复杂 CSS 选择器，减少选择器计算开销。
    • 使用 getElementCount 快速判断元素存在性，避免不必要的 DOM 遍历。
    • 合理使用 autoWaitAfterAction 的最小/最大等待，避免过长阻塞。
    • 无限滚动时使用 scrollAndCollect 的去重逻辑，减少重复内容处理。
  • 稳定性保障
    • 所有工具返回结构化结果对象 {success, message?, error?, ...}，便于上层统一处理。
    • 可见性检测与叠加层根判定避免误操作隐藏元素或嵌套层。
    • ref 失效时提供附近有效引用建议，辅助上层重试或重新查询。

故障排查指南 ​

  • 元素未找到
    • 检查选择器是否正确，是否被 Shadow DOM 包裹；尝试使用 queryInteractiveElements 获取最新快照与 ref。
    • 对于 clickByText，确认文本是否存在、是否可见、是否在可交互元素中。
  • 表单填充无效
    • 确认字段类型（text/select/checkbox/radio/contenteditable），富文本编辑器需使用 fillContentEditable。
    • 检查 React 受控组件是否通过 setNativeValue 正确更新值。
  • 点击无响应
    • 检查元素可见性（display/visibility/opacity/尺寸/视口），确保未被隐藏或折叠。
    • 使用 interactByRef 替代 CSS 选择器，避免选择器失效。
  • 滚动无进展
    • 检查滚动目标是否为 document.scrollingElement 或指定容器；确认已到达边界。
  • 键盘输入失败
    • 确认 activeElement 存在且可编辑；富文本编辑器需兼容 execCommand。
  • 文件上传失败
    • 校验 input.type==='file'；确保 fileContent 为 base64 或文本；确认 DataTransfer 赋值成功。

结论 ​

交互操作工具通过内容脚本层提供了完整的页面交互能力，涵盖元素定位、点击、表单填写、滚动导航、键盘模拟、文件上传与异步等待。其设计强调：

  • 强鲁棒性：严格可见性检测、叠加层识别、ref 引用与失效回退。
  • 高兼容性：Shadow DOM 穿透、React 受控组件兼容、富文本编辑器支持。
  • 可观测性：结构化结果对象、变化提示、附近引用建议。 在实际使用中，建议优先使用 ref 引用与 queryInteractiveElements，结合 autoWaitAfterAction 与 isElementTrulyVisible，构建稳定可靠的自动化流程。
