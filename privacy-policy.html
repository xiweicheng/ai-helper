AI Helper 隐私政策

最近更新：2026 年 10 月 28 日

结论先行

AI Helper 不收集、不上传、不出售任何用户个人数据。扩展没有自己的服务器，所有数据都只保存在你自己的设备本地，或发送给你自己配置的大语言模型服务。

一、数据的存储

  • 以下数据全部通过浏览器 chrome.storage 保存在你的设备本地：设置、智能体配置、自定义提示词、会话记录、长期记忆、执行日志、模型 API Key。
  • 扩展开发者无法访问上述任何数据，也不存在任何向开发者服务器传输数据的代码。
  • 语音音频从不落盘：录音只以内存中的音频分片存在，识别完成后立即释放，不会写入 chrome.storage、IndexedDB 或任何本地文件；只有识别出的文字会写进你的输入框。
  • 卸载扩展时，浏览器会一并清除这些本地数据。

二、数据的传输

  • 扩展唯一的网络请求，是调用你自行配置的大语言模型 API 端点（如 OpenAI 兼容接口、DeepSeek 等）。
  • 发送的内容仅包括：当前对话消息、你主动要求 AI 处理的页面文本/选中文本、以及工具运行所需的必要上下文。
  • 这些内容仅用于生成回复，其数据处理方式取决于你所选择的模型服务商的政策。
  • 若你启用本地语音输入，音频只会通过 127.0.0.1 回环地址发送到你自己启动的本地 Agent 服务做识别，不经过互联网，也不发往开发者或任何第三方。
  • 除你配置的模型端点外，扩展不向任何第三方发起包含用户数据的请求。

三、浏览器权限与数据访问

扩展声明的权限（标签页、书签、历史、下载、Cookie、剪贴板、网页内容读取等）均遵循同一原则：

  • 用户主动触发：只有当你在对话中明确要求 AI 执行相应操作（如"搜索我的书签"、"翻译选中文字"）时才会使用。
  • 本地处理：访问结果仅返回给你自己在侧边栏中查看，不会被记录、聚合或上传。
  • 调试功能：仅在用户明确要求排查网页问题时附着当前标签页，期间浏览器显示可见提示条，可随时取消，空闲 2 分钟自动脱离。
  • 麦克风（可选）：仅在你启用本地语音输入、并主动点 🎤 或按 Alt+V 之后才会访问。麦克风授权由浏览器在扩展页面内弹窗索要，需你显式同意一次；未启用该功能或未开始录音时，扩展不访问麦克风。
  • 语音识别完全离线：识别模型与 ONNX 运行时都跑在你本机的 Agent 进程内，音频不上传云端、不写磁盘，也不会被开发者访问。

四、儿童与敏感信息

本扩展面向通用用户，不针对儿童设计，不收集任何个人敏感信息。

五、政策更新与联系方式

若隐私实践发生变化，本页面将更新并在扩展发布说明中注明。如有疑问，请通过项目仓库提交 Issue：

  • 开源仓库：https://github.com/xiweicheng/ai-helper

AI Helper Privacy Policy

Last updated: October 28, 2026

Bottom Line

AI Helper does not collect, upload or sell any personal user data. The extension has no server of its own. All data stays on your device, or is sent only to the LLM service that you yourself configure.

1. Data Storage

  • All of the following are stored locally on your device via chrome.storage: settings, agent configurations, custom prompts, chat sessions, long-term memory, execution logs and your model API keys.
  • The extension developer cannot access any of this data, and there is no code that transmits user data to any developer-controlled server.
  • Voice audio is never written to disk: recordings exist only as in-memory audio chunks and are released as soon as transcription finishes. Nothing is written to chrome.storage, IndexedDB or any local file; only the transcribed text reaches your input box.
  • Uninstalling the extension clears all of this local data.

2. Data Transmission

  • The only network requests the extension makes are calls to the LLM API endpoint you configure yourself (OpenAI-compatible APIs, DeepSeek, etc.).
  • What is sent: the current conversation, page text / selected text that you explicitly ask the AI to work on, and the minimal context required for the tools to run.
  • This content is used solely to generate responses; its handling is governed by the policy of the model provider you chose.
  • If you enable local voice input, audio is sent only over the 127.0.0.1 loopback address to the local Agent service you started yourself for transcription. It never traverses the internet and never reaches the developer or any third party.
  • Other than your configured endpoint, the extension makes no third-party requests containing user data.

3. Permissions and Data Access

All declared permissions (tabs, bookmarks, history, downloads, cookies, clipboard, page content access, etc.) follow one principle:

  • User-initiated: used only when you explicitly ask the AI to perform the corresponding action (e.g. "search my bookmarks", "translate the selection").
  • Processed locally: results are shown to you alone in the side panel and are never recorded, aggregated or uploaded.
  • Microphone (optional): accessed only after you enable local voice input and actively click 🎤 or press Alt+V. The browser asks for microphone permission inside the extension page and requires your explicit consent once; while the feature is off or no recording is running, the extension does not touch the microphone.
  • Speech recognition runs fully offline: both the recognition models and the ONNX runtime live inside the Agent process on your own machine. Audio is not uploaded, not written to disk, and cannot be accessed by the developer.

4. Children and Sensitive Information

This extension is intended for a general audience, is not designed for children, and collects no sensitive personal information.

5. Policy Updates & Contact

If our privacy practices change, this page will be updated and the change will be noted in the extension's release notes. For questions, please open an issue on the project repository:
