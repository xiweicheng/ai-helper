💡 配置说明

推理循环是 AI 助手进行多步推理和工具调用的核心机制。
• 循环次数：决定 AI 可以进行多少轮推理-行动循环
• 超时设置：API 请求 / 整体循环 / 工具执行三项超时，防止长时间等待或无限循环
• 敏感操作确认：模型执行敏感操作前弹窗等待你确认，防止误操作
• 澄清等待：用户澄清时间不计入整体循环超时（自动暂停计时，非配置项）
• 建议根据网络状况和任务复杂度调整这些参数

💡 使用说明及安全提示 ▶

方式一：NPM 全局安装（推荐）
1. npm install -g ai-helper-agent（要求 Node.js ≥ 18）
2. ai-helper-agent start 或简写 aha start
3. 终端显示 6 位配对码，在此页面填入并点击"连接"

方式二：本地源码运行（开发调试）
1. cd agent && node bin/agent.js start
2. 终端显示 6 位配对码，在此页面填入并点击"连接"

命令别名：ai-helper-agent 可简写为 aha，所有命令均支持

后台运行：
　方式一：ai-helper-agent start -b 或 aha start -b
　方式二：node bin/agent.js start -b
更多命令：ai-helper-agent help 或 aha help

⚠️ 安全提示
代理服务默认仅监听本机地址（127.0.0.1），如需远程连接请修改启动参数。
文件操作限制在工作目录和白名单允许目录内，不可越权访问。
高危命令自动拦截，敏感命令支持配置化确认放行。
